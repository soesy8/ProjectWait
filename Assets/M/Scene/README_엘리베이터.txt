그 슛은 밖에서 보여줘! — 엘리베이터 이야기 체험

실행 씬
Assets/M/Scene/Elevator_Safety_Prototype.unity
Unity에서 씬을 열고 Play를 누릅니다. PC와 XR이 같은 진행 상태를 사용합니다.

이번 개선
- 한글 원본이 Thin으로 생성되던 문제를 수정했습니다. 공식 Noto Sans CJK KR Medium을 M에 추가하고, 본문 글리프를 정적 SDF 아틀라스로 구웠습니다. 추가 문자는 작은 동적 폴백을 사용합니다. 라이선스는 Arts/Fonts/NotoSansCJK-OFL.txt입니다.
- 대화·선택지는 인물과 장치 옆의 월드 공간에 배치하고, 관찰·독백·힌트는 별도의 화면 고정 카드로 분리했습니다. 말풍선과 청록 버튼은 베벨, 갈색 측면, 단계형 명암으로 입체감을 줍니다. 긴 선택지의 높이는 내용에 맞춰 늘어납니다.
- PC는 자유 포인터로 오브젝트와 UI를 클릭합니다. 우클릭을 누르는 동안만 둘러봅니다. 화면을 가로지르던 PC 레이저와 항상 보이던 조사 사각형은 제거했습니다.
- 비활성 벽·문, 중복 문 메시, 촘촘한 바닥 선 등 기존 환경 오브젝트 42개를 정리했습니다. 문과 손잡이·비상통화 패널의 모서리, 실내 명암을 다듬었습니다. 문은 열릴 때 옆 벽 뒤로 들어갑니다.
- 친구에게 눈 깜박임·놀란 입 모양·공 전달·몸 낮추기·슛·문에 손 뻗기·안심한 제스처와 반응 표시를 추가했습니다. 구조원은 기존 모델을 M의 별도 메시·복장으로 재구성했습니다.
- 공 전달, 통화 연결, 위치 발견, 안심, 구조 완료에 짧은 효과음을 추가했습니다. 실제 음성 합성은 사용하지 않습니다.

플레이 흐름
1. 농구를 마친 친구와 엘리베이터에 탑승합니다.
2. 친구가 들고 있는 공을 직접 클릭해 받습니다. 친구 옆 월드 버튼과 숫자 1로도 받을 수 있습니다.
3. 친구의 슛 재현과 엘리베이터 정지가 자동으로 이어집니다. 슛을 말리는 선택지는 없습니다. 플레이어의 카메라나 실제 몸은 뛰지 않습니다.
4. 비상통화 장치를 찾아 클릭합니다. 문을 직접 열려는 시도에는 안전 안내 후 다시 조사할 기회를 줍니다.
5. 먼저 “엘리베이터가 멈췄어요. 친구랑 둘이 있어요.”라고 상황을 알립니다. 이후 벽의 위치 표시를 직접 찾아 선택하고 건물명과 승강기 번호를 전달합니다. 위치를 찾기 전에도 상황 신고는 접수됩니다.
6. 문을 만지려는 친구를 클릭하거나 대사 버튼으로 안심시킵니다. 안전하게 기다리는 동안 농구 이야기를 세 번 이어갈 수 있습니다. 추가 대화는 필수가 아닙니다.
7. 구조원이 문을 열고 안전을 확인한 뒤, 안내에 따라 나갑니다. 마지막에는 표지·종이·링이 있는 3D 노트가 열립니다. 종이 표면의 Canvas에 완료 기록, 하이파이브 그림, 설명과 기록 보기·다시 시작 버튼이 표시됩니다.

PC 조작
- 좌클릭: 가리킨 물건·친구·버튼 선택
- 우클릭 유지 + 마우스 이동: 둘러보기. 놓으면 자유 포인터로 돌아옵니다.
- 숫자 1 / 2: 표시된 대사·행동 선택
- R: 처음부터 다시 시작하고 PC 시선 초기화
- Esc: 커서 해제
- F8: 개발 도구 열기/닫기. 단계 이동과 응답/무응답 전환
XR은 기존 컨트롤러 레이와 선택 입력을 유지합니다. 공 받기와 슛은 체험자의 실제 점프나 던지기를 요구하지 않습니다.

UI 배치와 재사용
- Elevator_World_Dialogue의 ElevatorSpatialUI에서 friendOffset, intercomAnchor/intercomOffset, rescuerAnchor/rescuerOffset, worldPixelSize로 월드 대화 위치와 크기를 조정합니다. 카메라를 돌려도 대화와 선택지의 월드 위치는 유지됩니다.
- Elevator_Screen_Thoughts는 PC에서 Screen Space Camera Canvas를 사용합니다. XR에서는 같은 정보를 카메라에 고정한 World Space 평면으로 표시합니다. 관찰 문구가 대사를 덮어쓰지 않고, 포인터가 떠나면 기본 힌트로 돌아옵니다. 화면 카드에는 입력을 받는 레이캐스터가 없습니다.
- Completion_3D_Notebook의 양쪽 PageSurface Canvas는 노트 면에 붙어 있습니다. notebookDistance/Offset/Tilt/Scale로 위치·기울기·크기를 조정합니다. 완료 단계에서 한 번 배치하므로 고개를 돌릴 때 노트가 따라오지 않습니다.
- Assets/M/Prefabs/ElevatorUI/에 WorldDialogue, WorldChoice, ScreenThought, OpenNotebook3D 표현 프리팹을 저장했습니다. 월드 프리팹과 노트 페이지에는 PC/XR 레이캐스터가 있고, 새 씬에서 이벤트와 카메라는 사용 목적에 맞게 연결합니다. 현재 체험의 버튼 진행 연결은 ElevatorView에서 처리합니다.
- 그림은 해상도에 독립적인 ElevatorMemoryGraphic으로 그립니다. 노트의 이미지·문구·완료 배지를 씬에서 각각 편집할 수 있습니다.
- Wait/M/Refresh Spatial UI Templates는 현재 표현을 M 프리팹에 갱신합니다. Apply Spatial Elevator UI는 아직 공간 UI가 없는 M 씬을 이 구조로 이관할 때 한 번만 사용합니다.

검증
- Unity 6000.3.18f1에서 컴파일 성공.
- 4:3·16:9·21:9에서 대화·선택지·노트 글자 잘림, 최초 시점의 노트 화면 이탈, 시선 회전 시 월드 위치 유지, 대사·관찰 분리와 기록 전환 검사: 82개 통과.
- Play Mode의 Input System 가상 마우스로 월드 버튼과 공·장치·위치 표시·친구를 클릭하고, 구조 완료 후 기울어진 노트의 기록 보기·다시 시작까지: 28개 통과. 검사 중에만 임시 입력 장치를 사용하고 종료 시 원래 입력 설정과 장치를 복원합니다.
- 로비·공 받기·조사·통화·위치 찾기·대기·재시도·구조·완료 화면을 캡처해 확인했습니다. Play Mode 프레임이 실제로 진행되는 것도 확인했습니다.
- 누락 스크립트·머티리얼, 셰이더 오류, CodexTemp 런타임 자산 의존성 없음. 재사용 프리팹의 스크립트 참조도 확인했습니다.
- 검증 결과와 캡처: Assets/M/CodexTemp/ElevatorQA/SpatialUI/
- 재현 도구: Assets/M/CodexTemp/SpatialUITools~/ReviewSpatialUI.cs, VerifySpatialInput.cs, FinishSpatialUI.cs
- 실제 HMD 착용, 컨트롤러 체감, 기기 빌드는 미검증입니다. 어린이 대상 사용성·재미 평가도 별도로 필요합니다.

작업 범위
구현과 저장은 Assets/M 안에서 진행했습니다. 공유 친구 모델·머티리얼과 XR 패키지는 읽기 전용으로 참조합니다. 초기 구성용 ElevatorPrototypeBuilder / ElevatorBasketballSetup / ElevatorPolishSetup의 Build를 다시 실행하면 현재 UI 구성이 달라질 수 있으므로, 저장된 씬의 ElevatorSpatialUI와 표현 프리팹을 기준으로 수정합니다.
