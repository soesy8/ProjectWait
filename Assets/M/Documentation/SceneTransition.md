# 물방울 페이드를 사용하는 이야기 씬 전환

## 바로 보기

- `Assets/M/Scene/Wait_Robby.unity`를 Play한 뒤 Game 뷰에서 **F8**: 현재 장면으로 돌아오는 전환 미리보기. 씬을 로드하지 않는다.
- Hierarchy의 `StorybookSceneTransition` 컴포넌트 컨텍스트 메뉴 **Preview story transition (Play Mode, no scene load)**로도 실행할 수 있다.
- 엘리베이터의 기존 **체험 시작** 버튼: 같은 연출을 표시하고 실제 `Wait_Elevator` 씬으로 이동한다.
- `Wait_Elevator` 단독 Play: 하늘/상황 안내 뒤 같은 물방울 효과로 등장한다. **F9**로 엘리베이터 내 왕복 미리보기를 재생한다. 기존 엘리베이터 F8 개발자 UI는 유지한다.
- 임시 `VR_Preview_Test` 루트는 현재 **비활성화**되어 있다. HMD가 없는 PC에서는 일반 PC 카메라·조작으로 확인한다. 코드·패키지·실제 XR 지원은 보존했으며 다시 시험할 때만 루트를 켠다.
- **K**는 기존 물방울 페이드 시험 그대로다. F8/씬 이동 중에는 중복 K 입력을 무시한다. 정전·횡단보도는 아직 준비 중 안내만 표시한다.

## 연출

**이전의 검은 화면 페이드는 제거했다.** 승인된 `LobbyDissolveTest`의 거리 기반 구/물방울 페이드와 반복 팝 사운드를 그대로 빌려 쓴다. 로비가 먼 곳부터 **2.5초 동안 물방울로 사라지고**, 마지막 구간부터 안내 카드가 나타난다. 모두 사라지면 **원래 하늘 배경 위에 카드와 점 3개가 떠 있다.**

카드는 최소 1.5초 유지한다. 종이색 둥근 카드, 갈색 테두리·단계형 그림자, 민트 배지와 청록 점 3개는 유지한다. 점은 같은 색이며 왼쪽부터 0.14초씩 늦게 작게 점프한다. 진행률이나 남은 시간을 의미하지 않는다.

### 자유 시점과 월드 패널

- 전환 중에도 **PC 마우스 시점, HMD 머리 추적, 로비 VR 스냅 회전**은 계속 처리한다. 걷기·선택·중복 전환 요청만 막는다. 로비에서 Esc로 커서를 풀었으면 클릭해 다시 고정할 수 있다.
- 패널은 나타나기 시작한 순간의 수평 시선 앞 **2m**, 실제 머리 높이에 가로 **1.65m**의 월드 앵커를 잡는다. 이후 고개/마우스를 돌려도 화면 중앙을 따라오지 않는다. 아래를 보고 포털을 눌렀더라도 카드는 기울이지 않고 눈높이에 배치한다.
- `t = 1-exp(-speed*dt)`와 Lerp/Slerp로 투명도·12cm의 짧은 상승/하강·작은 기울기와 스케일을 보간한다. 기본 속도는 12이며 프레임률에 독립적이다. 외부 트윈 패키지나 매 프레임 도형/텍스처 생성은 없다.
- 하늘 연결용 Canvas만 별도로 카메라를 따른다. 카드 Canvas와 분리되어 있어 하늘은 모든 시야를 가리면서 카드의 월드 위치는 유지한다. 씬 교체 때는 마지막 눈 위치에 대한 상대 배치만 새 카메라 좌표로 한 번 옮긴다.

### 정면 안내와 머리 기준 시점 연결

- 실제 씬 이동 시 카드에 **정면을 보고 있어 주세요.**를 표시한다. 카드 중심을 15도 안에서 기본 **0.4초** 바라보면 준비된 씬을 활성화한다. 로딩은 미리 진행하며, 시점을 강제로 돌리거나 HMD 추적을 멈추지 않는다. 미리보기·로딩 실패 복귀는 이 조건으로 막지 않는다.
- 카드를 벗어나 다른 방향을 보면 작은 종이색 안내 띠와 방향 화살표만 시야 아래쪽에 표시한다. 화살표는 고정된 월드 카드로 돌아갈 방향을 안내한다. 카드 자체는 머리를 따라 움직이지 않는다.
- 활성화 직전의 **바닥 대비 실제 눈높이**와 시선을 전달한다. 0층 로비와 7.92m 높이 체육센터 사이에서는 월드 Y를 그대로 복사하지 않고 각 씬 바닥을 기준으로 같은 높이를 유지한다. 로비 1.35m/엘리베이터 약 1.11m의 저장된 기본값으로 다시 맞추지 않는다.
- 도착 씬의 `Start`/추적 포즈 초기화 뒤, 하늘이 가린 상태에서 한 번만 리그를 보정한다. XR 카메라의 로컬 포즈는 변경하지 않고 추적 공간의 수평 회전만 이어받으므로, 로딩 중의 실제 고개 회전도 유지한다. 룸스케일 머리의 수평 오프셋은 도착 발판/캡슐 위치에 반영한다.
- 캡슐 발 위치·중력과 이후 도입 걷기에도 새 높이 오프셋을 유지한다. PC 시선 누적값도 동기화해 다음 마우스 입력이 시점을 되돌리지 않는다. XR은 전달받은 높이로 초기 보정을 완료하며, 재착용·추적 원점 변경·메뉴 재보정은 기존처럼 동작한다.
- 같은 전환 API로 엘리베이터→로비를 호출할 때도 적용하며, 돌아온 로비도 물방울 등장으로 연결한다. 새 로비 복귀 버튼을 추가한 것은 아니다.

> 친구와 농구를 마치고,  
> 이제 집으로 돌아가는 길이에요.

- **F8 미리보기:** 2.5초 물방울 소멸 → 1.5초 안내 → 같은 효과를 2.5초 역재생하여 로비 복원. 전체 약 6.5초이며 실제 씬을 로드하지 않는다.
- **실제 체험 시작:** 2.5초 물방울 소멸 → 최소 1.5초 안내/비동기 로딩 → **엘리베이터도 2.5초 동안 같은 물방울 효과로 등장**한다. 최소 약 6.5초이며 로딩·초기화가 길어지면 더 기다린다.
- **엘리베이터 단독 시작:** 최소 1.5초 안내/준비 → 2.5초 물방울 등장. 시작 시나리오가 전환 뒤에 재생되므로 대사를 건너뛰지 않는다.
- 물방울 렌더러가 없는 다른 씬은 기존 0.5초 하늘 연결 해제를 예비 경로로 남겼다. 현재 연결된 엘리베이터는 이 예비 경로를 사용하지 않는다.

하늘 가림막은 기존 파노라마 텍스처·틴트·노출·회전을 그대로 참조하는 XR 대응 UI 셰이더다. 새 스카이박스/캡처 텍스처/반사 카메라를 만들지 않는다. 사라진 로비의 하늘과 거의 같은 화면으로 씬 교체만 가린다. 메인 스레드 씬 활성화 중에는 점 애니메이션이 잠시 멈출 수 있으며, 별도 로딩 스레드/씬을 추가한 것은 아니다.

이동·선택·고정 HUD를 잠시 차단하되 시점 제어는 유지한다. 종료/취소 시 원래 HUD·패널 선택 상태를 복원한다. 엘리베이터 시나리오 시계는 전환 완료 후 시작하며, 포털/단독 시작 모두 첫 검은 화면 페이드를 물방울 연출로 대체한다. 재시작의 기존 시작 페이드와 이후 XR 이동 페이드는 유지한다. `Time.timeScale=0`에서도 실제 시간으로 진행한다.

기존 K 시험의 **3초/3초**, 구 간격·반지름·상한·색·외곽선·팝 설정은 바꾸지 않는다. 공통 물방울 렌더러를 한 번만 갱신하며, 캐시 메시를 재사용한다. 이미 K로 사라졌거나 K 페이드가 진행 중이면 F8/체험 시작은 그 상태를 강제로 덮어쓰지 않는다.

### 엘리베이터의 여러 재질 처리

`ElevatorSceneDroplets`는 기존 페이드 컴포넌트의 추가 씬 모드를 사용한다. 전환 때만 씬의 재질별 임시 복제본을 만들고, 종료/취소 후에는 **원래 재질 참조와 Canvas 상태를 복원하고 임시 재질·메시·팝 음원 풀을 해제**한다. 원본 재질/메시나 외부 임포트 설정은 바꾸지 않는다.

M의 Vertex Palette/Friend Atlas/Storybook/Ball 셰이더에는 기본값 0인 선택적 거리 마스크를 추가했다. 그림자·깊이·기본 외곽선에도 같은 마스크를 적용한다. 선택 외곽선 렌더 피처도 전환 전체를 끄는 대신 **같은 월드 거리·진행률로 coverage를 잘라** 사라진 물체의 윤곽이 남지 않게 한다. 원래 선택/강조를 표시할지 결정하는 게임플레이 정책은 유지한다.

URP Lit 소품은 `SceneLitDissolve.shader`로 **URP의 원래 Lit 조명 함수를 유지**하며 표면·그림자·깊이에 물방울 마스크만 더한다. 기존 재질의 속성·키워드·렌더 큐·투명도·블렌딩과 ShadowCaster 활성 상태를 보존한다. 기타 소품용 `ScenePropDissolve.shader`에도 그림자 수신/투사·알파 클리핑·투명도·안개 처리를 둔다. 보조 텍스트는 자기 위치의 표면이 완전히 드러나면 표시해 전환 끝의 일괄 등장을 줄인다. 고정 HUD는 기존처럼 종료 후 복원한다.

이전에는 전환용 단순 셰이더에서 빠졌던 조명·그림자·유리 투명도가 마지막 원본 재질 복원 시 한꺼번에 나타났다. 이제 **맵이 나타나는 동안부터 같은 명암과 그림자를 그리며**, 이 문제를 가리기 위한 추가 로딩 지연은 넣지 않았다. 패키지 셰이더는 수정하지 않았다. 현재 Forward 경로를 대상으로 하며 deferred/meta/motion-vector의 완전한 대체 셰이더는 아니다. Lit 임시 재질의 페이드 uniform은 URP 버퍼 밖에 있어 SRP Batcher 호환성과 기기별 성능은 별도 확인 대상이다.

읽기 가능한 메시와 캐릭터의 베이크된 표면에서 구를 배치한다. CPU 읽기가 꺼진 외부 소품은 임포트를 변경하지 않고 bounds 면으로 근사한다. 18m 안에서 최대 **1,800개** 구로 제한하며, 시나리오가 정지한 같은 왕복 연출에서는 메시를 캐시한다. 매 프레임 캐릭터를 베이크하거나 표면을 재추출하지 않는다.

## 수정 위치

- 공통 시간·미리보기 문구: 로비 루트 `StorybookSceneTransition` Inspector.
- 월드 패널 크기·거리·보간 속도: 같은 컴포넌트의 `Panel Width`, `Panel Distance`, `Panel Lerp Speed`. 엘리베이터 단독 실행용 컴포넌트에도 같은 기본값을 저장했다.
- 정면을 바라보는 시간: 같은 컴포넌트의 `Face Forward Seconds` (기본 0.4초).
- 대상 씬 상황 문구: 각 `TitlePortal.transitionContext`.
- 런타임: `Assets/M/Scripts/SceneTransition/`.
- 전용 폰트·머티리얼: `Assets/M/Arts/Fonts/SceneTransition/`, `Assets/M/Arts/Materials/SceneTransition/`.
- 하늘 연결 셰이더: `Assets/M/Arts/Shaders/SceneTransition/StoryTransitionSky.shader`.
- 조명 보존·보조 패스·외곽선 마스크: 같은 폴더의 `SceneLitDissolve.shader`, `SceneLitFade.hlsl`, `SceneDissolveAuxiliary.hlsl`, `ScenePropDissolve.shader`, `SceneOutlineCoverage.shader`.

전용 글꼴은 현재 문구에 필요한 129개 글리프를 가진 정적 1024×1024 한 장이다. 새 문구에 다른 글자가 필요하면 해당 글리프를 정적 아틀라스에 추가해야 한다. 공용 동적 한글 폰트는 이 UI에서 사용하지 않는다. UI 도형은 텍스처 없이 생성하며, 대기 중에는 점의 Transform만 갱신한다. 공식 씬과 런타임은 `CodexTemp`를 참조하지 않는다. 패키지·빌드 씬 목록·공용 설정은 변경하지 않았다.

## 확인과 산출물

시점 연결 검사는 **`Assets/M/CodexTemp/HeadPoseContinuity~/`**에 둔다.

- `Validation.cs`: Unity Pipeline `run_script`로 실행하는 일회성 검사. 정식 씬/런타임이 참조하지 않는다.
- `edit-validation.json`: 낮은/보통/높은 눈높이의 양방향 XR 리그 수학, 룸스케일 오프셋, 로컬 추적 포즈 보존·실제 머리 회전 유지, PC 시선, 재보정, 정적 폰트 글리프 검사.
- `runtime-validation.json`: 실제 로비 포털→엘리베이터→로비의 PC 비동기 씬 전환. 정면 대기, 눈높이·yaw/pitch 연결, 다음 프레임/도입 걷기/중력, 양방향 물방울 등장, 미리보기·취소 복원을 검사한다. 역방향은 전환 API로 호출한다.
- `scene-validation.json`: 두 씬의 Missing Script·참조 누락·임시 경로 의존성 없음, 기본 정면 대기값, Play 종료 후 원래 저장된 로비 복귀를 확인한다. 로직 29개·실행 22개·씬/정리 12개 검사 모두 통과했다.
- `01-forward-guide.png`, `02-elevator-arrival.png`: 시선을 벗어났을 때의 복귀 안내와 도착 순간의 카드. 테스트는 연출 시간을 줄여 실행하며 씬 파일은 저장하지 않는다.

실제 HMD의 추적 원점 전환 타이밍·양안 안내 가독성·착용감은 기기 검증이 별도로 필요하다. XR 자동 검사는 리그/보정 로직 검사이며 실제 HMD 왕복 체험을 대신하지 않는다.

최신 PC/그림자 연속성 결과는 **`Assets/M/CodexTemp/ShadowReadyPC~/`**다.

- `PCShadowReadyPreview.mp4`: 일반 PC 카메라로 렌더한 **무음 F9 왕복 미리보기**. 1280×800, 20fps, 0.05초 고정 틱이며 실제 로딩의 연속 녹화나 성능 측정은 아니다.
