# 플레이어 대사 화면 하단 배치

- VR/PC 상·하단 레터박스를 각각 200/720 기준으로 통일했다.
- ‘나’ 대사만 별도 화면 고정 패널로 표시한다. PC는 Screen Space Overlay, VR은 실제 양안 투영을 사용하는 카메라 정면의 고정 UI 평면이다. 다른 화자의 오브젝트 말풍선은 유지한다.
- 패널 중심 Y = 하단 레터박스의 위쪽 경계 + 패널 높이/6. 따라서 레터박스 경계가 패널 아래에서 1/3 지점을 지난다. 가변 대사 높이에도 같은 비율을 적용한다.
- VR에서 띠가 등장하는 도중이나 시야가 좁을 때에는 패널과 이름표를 양안 안전 영역 안으로 보정한다. 패널은 검은 띠보다 위에 그리며, 전체 암전/일시정지/씬 전환 중에는 숨긴다.
- 플레이어 화면 패널과 기존 월드 말풍선이 중복 표시되지 않도록 분리했다. VR 목표 안내는 플레이어 패널 위쪽으로 겹침을 피한다.
- 사용자 요청에 따라 이번 변경은 컴파일, 자동 하네스, 실기기 및 시각 검증을 실행하지 않았다. 기존 검증 결과는 이전 구현에 대한 기록이며 이번 변경의 통과 결과가 아니다. 기존 PC 82 높이 및 플레이어 월드 말풍선 기대값을 사용하는 검증 항목은 다음 검증 시 갱신이 필요하다.
