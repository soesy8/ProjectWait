# VR 대화 월드 고정 배치 — 2026-11-13

실기기 피드백에 따른 후속 변경이다. 대화 위치·구조요원 표시 소유권·VR 레터박스에 관해서는 이전 `VRUIComfort_20261113.md`보다 이 문서와 현재 코드를 우선한다. PC 배치, 대사 내용, 선택 콜백과 진행 판정은 유지한다.

## 배치

- **탑승 전:** 맵에 지정된 플레이어 대기 위치와 친구 위치 사이, 친구 옆의 플레이어 정면 쪽에 대화와 선택지를 함께 생성한다.
- **승강기 내부:** 맵의 내부 플레이어 기준 위치에서 문 방향 1.4m 앞의 고정 위치를 사용한다. 통화·관찰·친구 대화·선택지가 바뀌어도 같은 위치를 사용한다.
- **구조요원:** 내부 기준 문 방향 1.65m 앞, 시청자 기준 좌측 0.35m, 기준 눈높이보다 0.28m 위에 생성한다. 생성 시 실제 플레이어 위치를 바라보게 한 뒤 위치·회전을 고정한다. VR 구조요원 대사는 월드 카드가 담당하고 중복 자막은 표시하지 않는다. PC 구조요원 자막 정책은 유지한다.
- **구조 후 로비·1층:** 각 맵의 대기 위치 앞에 별도 고정 기준점을 둔다.
- 대화·선택지·살펴보기 카드는 월드 Canvas에 둔다. 살펴보기 보조 카드는 같은 월드 루트의 좌측 고정 슬롯을 쓰며, 머리를 따라가는 HUD의 자식으로 두지 않는다.
- 기준점은 한 실행의 구역별로 한 번 기록한다. 고개 회전·이동, 자막 표시, 내용·선택지 개수, 눈 투영 변화는 기준점을 움직이지 않는다. 새 실행/재시작 때만 초기화한다. 카드를 시야 밖에 두고 고개를 돌리면 따라오거나 사라지는 대신 같은 장소에 남는다.
- **조작 가이드:** 우측 18°/위 12°에서 **우측 21°/위 14°**로 조금 이동한다. 카드 전체가 양안 안전영역에 들어오도록 보정하는 기존 처리는 유지한다.

## 레터박스와 컷씬

- VR 상단 띠는 계속 사용하지 않는다. **하단 띠의 기준 높이만 82/720 → 246/720(3배)**로 늘린다. 눈별 비대칭과 화면 밖 overscan 여백은 별도 유지한다.
- 컷씬 자막은 작은 독립 카드 위치가 아니라 확대된 하단 검은 영역 **안쪽**에 놓는다. 실제 줄바꿈 높이와 양안 공통영역을 사용하며, 폰트 크기는 유지한다.
- 자막의 기본 중심은 아래 28°이며, 긴 문장은 띠 안과 두 눈의 안전영역을 만족하도록 보정한다. 중앙 월드 카드의 수직 ±26° 제한과는 별개다.
- 띠가 올라오는 애니메이션 중 글 전체가 들어갈 높이가 없으면 잠시 글만 숨긴다. 정면으로 튀어나오는 fallback은 사용하지 않는다.
- 일반 컷씬은 확대된 레터박스 자막, 구조요원 대화는 지정된 월드 카드로 표시해 같은 대사가 중복되지 않게 한다. 전체 comfort fade와 기존 컷씬 진행 시간은 유지한다.
