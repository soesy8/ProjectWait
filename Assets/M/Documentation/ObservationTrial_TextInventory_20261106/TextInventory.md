## 읽는 방법

- **표시**: 현재 오브젝트 중심 진행에서 화면에 나오는 문구.
- **조건부**: 선택·분기·카메라 방향·일시정지·개발 도구 등에 따라 나오는 문구.
- **숨김**: 문자열이 만들어져도 현재 UI 표시 규칙으로 가려지는 문구.
- **미사용**: 현재 정상 경로에서 진입하지 않는 단계, 비활성 구형 오브젝트, 호출되지 않는 폴백.
- `<br>`는 원문의 강제 줄바꿈입니다. 자동 줄바꿈은 화면 폭에 따라 달라집니다.
- **공간 카드**는 `Elevator_World_Dialogue/StoryCard`, **자막**은 화면 아래 검은 띠의 `CinematicSubtitle`, **HUD**는 화면 가장자리의 작은 제목·지시 카드입니다. 수첩과 메뉴는 별도입니다.
- 일반 자막은 `화자  ·  본문` 형식입니다. 카드 원문의 강제 줄바꿈은 자막에서 공백으로 바뀝니다.
- 아래의 시간은 단계 진입 후 경과시간입니다. 일시정지·텍스트 읽기·물체 선택 대기시간은 포함하지 않습니다.
- 현재 저장 설정은 `objectGuidedScene = true`, `simulateNoResponse = false`입니다. 기본은 관리실 연결이며 119는 무응답 분기입니다.

### 범위와 근거

현재 씬의 TMP 컴포넌트 **172개**, 모델 원본의 문자 본문 **113개**, 런타임 코드의 한글 문자열 리터럴 **295개**를 교차 확인했습니다. 이 숫자는 고유 대사 개수가 아닙니다. 반복·비활성·빈 문자열·내부 이력도 포함합니다. 구형 `TextMesh`, `UnityEngine.UI.Text`는 실행 중 스냅샷에서 0개였습니다. 이미지에 박힌 포스터 글씨도 별도로 확인했습니다.

- [원본 전체 부록](RawTextAppendix.md): 172개 Hierarchy 경로, 113개 모델 문자 위치, 295개 코드 문자열과 소스 줄 번호.
- `LiveTextSnapshot.json`: 실행 중 Lobby/일시정지 UI가 열린 시점의 원본. 단일 시점이므로 이후 대사는 코드 흐름과 함께 확인했습니다.
- `ObservationObjects.json`: 관찰 오브젝트와 활성 상태. 이후 읽기 전용 확인 시 에디터는 재생 정지 상태였습니다.
- `ReadOnlyContext.json`: 마지막 확인에서 대상 씬은 열려 있고 저장되지 않은 변경이 없었습니다. 사용자 재생을 시작·정지하거나 단계를 조작하지 않았습니다.

## 12. 내부 기록 — 화면 문구와 구분

`ElevatorFlow.History`에는 농구 종료, 공 받기, 목적지 선택, 비상통화·119, 식별판 확인·위치 전달, 문에 기대려 한 첫 시도, 안전 벽 이동, 구조·귀가, 개발 단계 생략 등의 문장이 기록됩니다. **현재 수첩은 History 원문을 출력하지 않고 N12–N15의 별도 고정 문구를 사용합니다.**

따라서 `친구가 만류를 듣지 않고…`, `→ Wait! 중단 후 재도전`, `개발용 단계 이동: 앞 단계 생략` 같은 기록을 현재 대사로 볼 필요는 없습니다. 원문은 원본 부록의 `ElevatorFlow.cs`, `ElevatorLesson.cs` 행에 전부 남겼습니다. 상황 보고 D11만 Settings 문자열을 이력에도 함께 저장합니다.

## 13. 이후 전면 수정 시 확인할 지점

이 문서는 수정안을 적용하지 않았습니다. 현 상태에서 특히 구분해야 할 점은 다음과 같습니다.

1. **어디에 글씨가 뜨는가부터 다름:** 컷씬 자막, 공간 대화, HUD, 물체 설명, 수첩이 각각 다른 문구를 갖고 있습니다.
2. **구조대 대사와 마지막 친구 대사는 현재 안 보임:** X05–X08의 원문만 고쳐도 실제 플레이 화면은 바뀌지 않습니다.

5. **무응답 설명의 숨김:** 실제 전화가 아니라는 긴 안내 X03은 보이지 않으며 휴대폰 직접 클릭은 O17도 건너뜁니다. 119 통화 화자 표기에는 `모의 통화`가 남습니다.
6. **표시 위치 문구:** D13·H03은 `문 옆`, 씬의 실제 식별판은 전면 비상벨 아래입니다. 조작 위치와 문장을 함께 검토해야 합니다.
7. **표현이 섞임:** `엘리베이터/승강기`, `비상통화/비상벨/비상 호출`, `관리실/119 · 모의 통화`, 구조 대사의 여러 호칭이 혼재합니다.
8. **포스터 원문은 이미지:** §7을 고치려면 텍스트 코드뿐 아니라 M 내부 포스터 이미지도 별도 수정해야 합니다. 배경 표지는 모델 문자와 TMP가 중복됩니다.
