## 코드와 렌더링

- ScenarioDirector의 매 프레임 Canvas/Graphic 검색을 제거했습니다. 초기화 및 UI 내용이 바뀔 때만 공유 머티리얼을 준비하며 재사용 List를 씁니다. 관찰 설명도 대상·단계·실행 회차가 바뀔 때 갱신합니다.
- 생각 말풍선 헤더와 전환 텍스트 수집을 캐시합니다. 새 UI 자식이 생기면 계층 개수로 갱신합니다. 헤더 캐시는 약한 참조를 사용합니다.
- 층수 문자열, 층 버튼 머티리얼, 안내 문자열 및 얼굴 메시를 값이 바뀔 때만 적용합니다. 친구 표정의 중복 담당을 줄였으며 재시작·메시 교체를 지원합니다.
- 구조요원 충돌 제외는 활성화·플레이어 변경 시 설정하고 매 프레임 배열을 만들지 않습니다. 플레이어 위치 전환 후에도 충돌 제외가 유지되는 것을 재생 중 확인했습니다.
- 공용 Highlight 파일은 수정하지 않았습니다. M 전용 ElevatorOptimizedOutlineFeature를 연결하고 대상 목록을 재사용하며 강조 대상이 없을 때 깊이 패스를 요구하지 않습니다. 확장 탐색 시작 폭도 필요한 범위로 줄였습니다. 32비트 거리 데이터 정밀도와 XR 스테레오 처리는 유지합니다.
- 그림자는 4 Cascade/60m에서 2 Cascade/35m로 조정했습니다. MSAA 4x, 기존 색상, 셀 명암 및 외곽선 스타일은 유지합니다.
- 팔레트 메시의 사용하지 않는 Tangent/UV0를 제거하고, 기존에도 뒷면을 버리던 재질에만 하드웨어 Back Culling을 적용합니다.

## 자산과 구조

- 구조요원은 원본 FBX와 Generated 원본 메시를 보존하고 Optimized 하위에 별도 런타임 메시를 만들었습니다. 뼈·가중치·정점 팔레트 데이터를 유지합니다. 쓰이지 않는 구조요원 BlendShape는 런타임 메시에서 제외했습니다. 원본은 그대로 남아 재생성할 수 있습니다.
- 오프라인 표면 비교는 모든 경량 정점과 원본 정점의 조밀한 샘플을 사용했습니다. 구조요원 표면 오차는 A 약 0.81mm, B 약 0.67mm입니다. 모든 애니메이션 자세에서의 엄밀한 최대 오차를 보증하는 수치는 아닙니다.
- 충돌 메시 후보 93개에 67,518개의 방향별 레이 비교를 실행했습니다. 68개를 채택하고 판정 차이가 난 25개는 원본으로 복원했습니다. 콜라이더 개수는 152개로 유지하며 참조 누락은 없습니다.
- 씬마다 참조 없는 빈 그룹 630개를 제거했습니다. 전체 오브젝트 차이에는 폰트 통합 후 사라진 TMP 보조 메시도 포함됩니다.
- 3층 문이 닫힌 내부 장면에서만 접근 불가능한 1층 지오메트리를 비활성화하고 문이 열리기 전 및 1층 전환 때 복구합니다.
- 중복된 공용 생각 말풍선을 M 전용 프리팹으로 복제하고 폰트·이미지 참조를 M 자산 한 세트로 통일했습니다. 동일한 한글 폰트 원본 한 벌이 씬 의존성에서 빠졌습니다.
- UI 텍스처 최대 크기를 1024로 제한했습니다. 블록 압축을 지원하는 크기의 이미지는 PC BC7/Android ASTC 4x4로 설정했습니다. 비정규 크기 슬라이스 스프라이트는 RGBA32를 유지해 테두리·알파를 보존합니다.
- 현재 Sprite Packer 설정은 Disabled입니다. 아틀라스 사용을 위한 공용 ProjectSettings 변경은 M 범위 밖이므로 적용하지 않았으며 시험용 미사용 아틀라스도 제거했습니다.
- 런타임에서 정점 데이터를 읽지 않고 충돌체와 공유하지 않는 메시 184개의 CPU 읽기 사본을 제거했습니다. 일반 충돌 메시의 읽기 설정은 보존했습니다.
