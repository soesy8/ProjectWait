# VR UI 후속 조정 — 2026-11-13

이번 요청의 네 항목만 적용했다. 테스트 기능 정리, 컨트롤러/스폰 재작업 및 추가 최적화는 하지 않았다. 씬·머티리얼·폰트·패키지·프로젝트 설정은 수정하지 않았다.

## 변경

- **레터박스:** VR 상·하단 각각 `200/720`. 같은 높이와 기존 슬라이드/암전 처리를 유지한다. PC의 기존 `82/720`은 유지한다.
- **목표 안내:** 대화창이 시야에 있다는 이유만으로 숨기지 않는다. 머리/카메라 중앙 시선이 실제 활성 대화 카드 안에 닿을 때만 숨긴다. 이름표, 선택지, 손 레이, 비활성/투명 대화창은 숨김 조건이 아니다.
  - 나타남/사라짐 모두 1초 SmoothStep이며, 도중 시선을 되돌려도 현재 투명도에서 이어진다. 페이드 종료 전 오브젝트를 비활성화하거나 글자를 지우지 않는다.
  - 안내 전용 CanvasGroup으로 일반 HUD의 컷씬 페이드와 분리했다. 유효한 안내가 있으면 컷씬이라는 이유만으로 숨기지 않는다. 일시정지·씬 전환의 Canvas 숨김 및 안내가 없는 단계/완료 처리는 유지한다.
- **구조대 카드:** 실내 높이 오프셋 `눈높이 + 0.28 → +0.50m`로 22cm 높였다. 이름표/선택지까지 양안 읽기 범위에 들어오도록 전방 깊이는 `1.65 → 2.10m`로 조정했다. 글자 크기는 유지한다.
  - 3층 외부 카드는 플레이어 뒤쪽을 향하던 이전 기준을 제거하고 친구 위, 두 구조요원 사이의 중앙에 배치한다. 친구와 구조요원 사이의 깊이를 사용해 카드가 머리와 겹치지 않게 한다.
  - 3층 중심 X/Z는 기본 배치에서 `(-1.80, -3.95)`, 1층은 `(-0.55, -3.05)`. 높이는 해당 층 바닥 + 첫 배치 시 눈높이 + 0.50m이다.
  - 외부에서도 플레이어를 향해 한 번 배치한 후 월드에 고정한다. 고개를 돌리거나 자막/선택지가 바뀐다고 따라오지 않는다.
- **도입부 타이밍:** 친구의 이동/전체 도입 길이/문 연출은 그대로다. PC 플레이어 경로를 `0.4–7.1 → 0.6–7.3초`로 통째로 이동해 속도를 바꾸지 않고 0.2초 늦췄다. 경로에 맞춘 PC 회전도 함께 지연한다. VR 텔레포트는 `4.2 → 4.4초`이며 기존 comfort fade도 같은 시점에 맞춰진다.
