# 대화·알림 개선 테스트 씬

## 실행

`Assets/M/Scene/Elevator_Dialogue_Preview_Test.unity`를 열고 Play를 누릅니다.

메인 씬 `Elevator_Obsevation_Choice_Test.unity`와 빌드 등록은 바꾸지 않았습니다. 이 씬은 비교용이며 자동으로 빌드에 포함되지 않습니다.

## 변경 내용

- PC의 클릭 안내와 VR의 검지 트리거 안내를 구분하고 입력 장치 그림을 맞췄습니다.
- 첫 조작 시 기본 이동·메뉴 안내를 잠깐 표시합니다.
- 친구의 반복 대사와 탑승·퇴장·귀가 중계 자막을 줄였습니다.
- 관리실 안내 뒤의 버튼을 `찾아볼게요`로 바꾸고, 위치 탐색 힌트는 시간이 지나면 구체화합니다.
- 포스터를 먼저 확인하지 않아도 두 대답을 같은 색·그림으로 제시합니다. 안전 선택지와 실제 대사는 같은 문장을 사용합니다.
- 문에 기대지 않기·강제로 문을 열지 않기·구조 안내 기다리기는 유지합니다. 뛰지 않기 안내는 안전 카드와 완료 화면의 짧은 문구로 분리했습니다.
- 메뉴를 `계속하기 / 처음부터 다시 하기 / 체험 끝내기`로 바꾸고, PC에서는 눈높이 보정 버튼을 숨깁니다.
- VR 눈높이 보정의 행동 버튼과 대기·완료 메시지를 구분합니다.
- 완료 화면의 중복 표제를 줄이고, 세부 기록은 `함께한 일 보기`에서 확인합니다.
- 최종 글자 영역을 기준으로 선택지 높이를 계산하고, 안전 안내의 어미가 한 줄에 따로 떨어지지 않도록 조정했습니다.

타입 참조가 결합되어 있는 런타임을 테스트 전용으로 복제했습니다. 앞으로 이 실험의 문구를 바꿀 때는 위 전용 경로를 사용합니다. 모델·재질·폰트·공통 렌더링 자산은 원본을 수정하지 않고 공유합니다. 친구 프리팹에서 상속되는 표정 컴포넌트도 전용 타입으로 연결했습니다.
