# 대화 문구와 중앙 투명 영역 수정

- 테스트 씬과 전용 설정만 수정합니다. 세 가지 행동, 선택 결과, 재시도 지점과 기존 시간 설정은 유지합니다.
- 친구끼리는 편한 말투로, 통화 상대와 구조요원은 짧은 존댓말로 말합니다.
- ‘선택’, ‘클릭’, ‘카드’는 캐릭터가 말하지 않습니다. 물리적인 버튼을 눌러 달라는 부탁은 대화에 남깁니다.
- 조작 설명은 HUD와 행동 버튼, 안전 수칙은 안내 문구로 구분합니다.

## 대표 변경

| 장면 | 이전 | 수정 |
|---|---|---|
| 공 받기 | 1층 눌렀구나! 공을 선택해서 받아 줄래? | 고마워! 내 공 좀 잠깐 받아 줄래? |
| 통화 연결 | 연결됐습니다. 무슨 상황인가요? | 관리실입니다. 무슨 일이세요? |
| 위치 전달 | 본관 1호기 · HB-EL-01에 있어요. | 한빛 생활체육센터에 있어요. 번호는 HB-EL-01입니다. |
| 불안한 친구 | 아까 덜컹해서 놀랐어… 다리가 조금 후들거려. 잠깐 문에 기대도 될까? | 아직 좀 무서워… 다리가 떨리는데, 문에 잠깐 기대도 될까? |
| 안전한 대답 | 문에서 떨어져 같이 기다리자. | 옆 벽으로 가서 같이 기다리자. |
| 구조 후 이동 | 저희를 선택하면 계단으로 1층까지 함께 내려갈게요. | 엘리베이터는 점검해야 해요. 계단으로 1층까지 안내할게요. |
| 친구와 나가기 | 주출입구를 선택해서 함께 나가자. | 휴, 이제 좀 안심이 된다. 우리 집에 가자. |

공통 대사의 실제 목록은 `DialogueCopy.json`에 기록합니다. 말풍선과 연출 자막은 같은 원문을 사용하되, 자막에서는 강제 줄바꿈을 풀어 기존 두 줄 영역 안에서 읽을 수 있게 합니다.

## 투명 영역

기준 반경의 수평·수직 탄젠트 값에 배율 2를 적용합니다. 같은 깊이에서 폭·높이가 각각 2배가 됩니다. 종이·테두리·장식에만 적용하며 글자·대답·진행 버튼은 유지합니다. 입력 통과 판정에도 같은 반경을 사용합니다.

## 확인할 점

- 친구의 말투와 통화·구조 안내가 서로 구분되는지
- 대사에 조작 설명이 다시 끼어들지 않는지
- 1층·119·승강기 번호가 잘리지 않고 정확하게 표시되는지
- 넓어진 투명 영역에서 글자와 버튼이 계속 읽히고 선택되는지
- HMD에서의 실제 가독성과 말투에 대한 사용자 반응은 별도 확인 필요
