# 레터박스 자막 → 발화 위치 말풍선 — 2026-11-13

## 적용

- 레터박스 배경과 연출을 그대로 유지했다. VR 상·하단은 각각 `200/720`, PC는 기존 `82/720`이다. 등장/퇴장, 시작 암전, XR 텔레포트 comfort fade의 타이밍/형상은 바꾸지 않았다.
- `ElevatorCinematicOverlay`에서 텍스트 생성·대사 선택·자막 크기 계산을 제거했다. 검은 띠에는 대화나 안내 문구를 출력하지 않는다. 이전 씬의 `CinematicSubtitle`은 참조/GUID를 보존한 채 비활성화하며, 런타임에서도 텍스트를 비우고 표시를 차단한다.
- 안전 안내 살펴보기/비상통화 연결 대기처럼 진행에 필요한 비대화 지시는 목표 안내 패널에 유지해, 자막 제거 때문에 해야 할 일을 알 수 없게 되지 않도록 했다.
- 별도의 중복 대화 UI를 만들지 않고 기존 종이색 대화 카드·화자 이름표·말풍선 꼬리·선택지 패널을 재사용한다. 컷씬에서도 이 말풍선으로 대사를 보여 준다.
- `ElevatorSpeechAnchor`가 현재 화자/선택한 오브젝트에 따라 위치를 연결한다.
  - 친구 → 친구의 머리 근처.
  - 소방 구조대원 / 승강기 담당자 → 각각의 구조요원 머리 근처.
  - 관리실 / 119 → 실제 인터폰 / 휴대폰 위치.
  - ‘나’ → 플레이어 리그 기준으로 한 번 정한 1인칭 발화 위치. HMD의 로컬 포즈를 쓰거나 고개 방향에 따라 매 프레임 재배치하지 않는다.
  - 식별판 등 관찰/확인 카드 → 해당 오브젝트 위치.
- 패널은 대상 옆에서 대상의 이동을 따라가며, 화자/발신 위치를 향하도록 꼬리를 회전한다. 고개를 돌린다는 이유만으로 화면 앞에 끌려오지 않는다. 플레이어 위치가 달라지면 읽을 수 있도록 패널의 면만 플레이어를 향한다.
- 대사 내용, 순서, 기존 시간 기반 전개, 선택 콜백 및 컷씬 중 입력 제한을 유지한다. 시작 친구 대사/슛 동작 대사의 기존 종료 시점도 유지한다. 새로운 음성/TTS는 추가하지 않았다.
- 완료 노트, 목표 안내의 중앙 시선 조건·1초 페이드, 도입부 플레이어 0.2초 지연 및 스폰/컨트롤러 처리는 유지한다. 테스트 기능 정리는 하지 않았다.
