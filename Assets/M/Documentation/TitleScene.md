# Wait_Title

`Assets/M/Scene/Wait_Title.unity`는 세 가지 상황을 고르는 작은 체험 광장이다. 사용자가 변경한 현재 씬 이름과 GUID를 유지한다.

- 왼쪽: 회색 문 두 기, 중앙 호출판, 3F 표시가 있는 엘리베이터 로비.
- 정면: 앞이 열린 정전 사무실. 조명과 구형 모니터 화면은 꺼져 있다.
- 오른쪽: 산호색 자동차, 보행자 신호등, 횡단보도로 구성한 짧은 도로.

세 구역의 앞면은 플레이어 시작 위치를 바라본다. 엘리베이터와 횡단보도를 좌우 안쪽으로 돌려 플레이어를 둘러싸는 배치로 구성했다. 선택 패널은 시작 위치를 중심으로 약 2.15m 반경의 왼쪽 58도·정면·오른쪽 58도에 배치했다. 실제 이동 영역은 기존 가로 9.6m, 깊이 3.8m를 유지한다.

## 조작과 연결

- PC: WASD 이동, 마우스 둘러보기, 중앙 점으로 패널을 가리킨 뒤 왼쪽 클릭. Esc로 커서를 풀거나 다시 고정한다.
- 실제 XR 장치가 활성화되면 머리 추적, 왼손 스틱 이동, 오른손 스틱 30도 회전, 오른손 트리거 선택을 사용한다. Mock HMD에서는 PC 조작을 유지한다.
- 엘리베이터 패널은 기존 `Wait_Elevator` 씬을 연다.
- 정전·횡단보도는 이번 작업에서 전시 공간만 구현했다. 패널을 누르면 준비 중 안내를 표시한다. 추후 각 `TitlePortal.destinationScene`에 대상 씬 경로를 연결한다.

## 자산과 렌더링

사무실 모델은 `origin/B`의 Office Set, 자동차는 `origin/Y`의 SoftCar를 새 GUID로 M 내부에 가져왔다. 복제 원본과 새 메시·머티리얼·글꼴은 `Assets/M/Arts/`의 각 `TitleScene` 하위 폴더에 있다.

`TitleSceneRenderProfile`은 플레이 중에만 M 전용 URP 프로필을 사용하고 씬을 떠나면 기존 프로필을 복원한다. 공유 프로젝트 설정과 기존 엘리베이터 씬은 수정하지 않는다. 빌드 씬 목록도 변경하지 않았다.

## 단일 텍스처·머티리얼 구성

3D 지오메트리는 바닥·배경·세 전시 구역·세 패널의 8개 메시로 통합했다. 각 메시에는 하나의 서브메시, 하나의 공통 머티리얼과 하나의 공통 색상 아틀라스를 사용한다. 갈색 외곽선 지오메트리도 같은 메시와 머티리얼로 그린다. 중복 정점은 색상·노멀·외곽선 구분을 유지하면서 합쳤다.

- 3D 메시 렌더러: 421개 → 8개.
- 3D 지오메트리 사용 머티리얼: 33개 → 공통 1개.
- 정점: 102,562개 → 78,468개.
- 색상 아틀라스: 32 × 64, 밉맵 없는 공통 텍스처 한 장.
- 동적 한글 UI는 기존 공통 글꼴 아틀라스를 사용하고, VR 포인터는 별도의 단일 텍스처·머티리얼을 사용한다.

최적화 자산은 `Arts/Models/TitleScene/Optimized/`, `Arts/Materials/TitleScene/Optimized/`, `Arts/Textures/TitleScene/Optimized/`에 있다. 도구와 변경 전 씬 백업은 `Assets/M/CodexTemp/TitleLayoutTools~/`에 보관한다. 정식 씬은 이 임시 폴더에 의존하지 않는다. 이미 통합된 씬에 `OptimizeTitle.cs`를 다시 실행하지 않는다.

## 확인 범위

최초 구현에서 이동·경계·패널·씬 전환을 확인했다. 이번 배치 변경과 아틀라스 최적화는 저장했으며, 사용자 요청에 따라 추가 플레이 검증과 실제 HMD 검증은 미뤘다. 최초 구현의 검증 결과를 현재 변경의 플레이 검증 결과로 간주하지 않는다.
