# 배포 전 실기기 확인

이 문서는 자동 회귀 검사로 대신할 수 없는 확인 항목입니다. 현재 에디터·가상 입력·GPU 검사는 실제 HMD 착용이나 기기 성능을 검증하지 않습니다. 실제 플레이어 빌드는 사용자 결정에 따라 이번 작업에서 수행하지 않습니다.

## 착용·조작

- [ ] 책상 위에 둔 HMD를 착용하기 전에 높이가 확정되지 않는다.
- [ ] 착용하고 정면을 편하게 보면 잠시 안정화 후 정상 눈높이가 된다.
- [ ] 착용 감지 미지원 기기에서는 일시정지 메뉴의 **정면 보고 높이 맞추기**를 트리거로 선택하고 안정된 자세를 유지한다.
- [ ] 진행 중 메뉴의 **높이 다시 맞추기**로 재설정된다. 벗었다 다시 쓰거나 추적 원점이 바뀐 뒤에도 잘못된 높이가 남지 않는다.
- [ ] 양손 모두 물체와 UI를 검지 트리거로 선택하고, 그립만으로는 선택되지 않는다.
- [ ] 물리 보행·기울이기·스틱 이동·일시정지·통화 컷씬에서 머리가 벽을 넘어가지 않는다. 물리 경계/Guardian을 항상 유지한다.

## 가독성·편안함

- [ ] 양쪽 눈에서 한글 안내·메뉴·식별판 번호가 잘리고 겹치지 않으며 읽을 수 있다.
- [ ] 포스터·시설 안내와 비상벨 위치 힌트가 잘 보인다. 계속 가리켜도 시간 힌트가 이를 지우지 않는다.
- [ ] 회전·암전·이동·재보정에 갑작스러운 흔들림/불쾌감이 없다. 불편하면 즉시 중단한다.
- [ ] 초심자가 도움 없이 선택·일시정지·식별판 찾기·위치 전달을 수행한다. 실패한 단계/문구를 기록하고 그 부분만 개선한다.

## 기기 빌드·성능 (별도 승인 후)

- [ ] 실제 배포 기기와 런타임으로 빌드/실행한다. 에디터 성공과 별도로 기록한다.
- [ ] 기기 고유 주사율의 프레임 예산 내에서 CPU/GPU와 드롭/재투영을 측정한다. PC의 60 FPS 제한값을 XR 목표 주사율로 간주하지 않는다.
- [ ] 두 통화 경로, 구조 후 계단·1층 도착·귀가·재시작을 끝까지 실행한다.
- [ ] 장시간 실행의 열·메모리·추적 재연결·일시정지 복귀를 확인한다.

## 결과 기록

`기기/런타임/주사율 · 검사자 · 통과/실패/미검증 · 재현 단계 · 화면/Profiler 근거`를 `Assets/M/CodexTemp/` 안에 저장합니다. 빈 체크박스는 통과가 아니라 **미검증**입니다.
