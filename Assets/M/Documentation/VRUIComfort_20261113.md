# VR 읽기 UI 시야 배치 개선 — 2026-11-13

이 문서는 `VRImprovement_20261113.md` 이후의 **추가 5개 시야 개선** 기록이다. 초기 구현 기록의 UI 거리/위치 설명보다 이 문서와 현재 코드를 우선한다.

## 적용 범위

카메라 FOV, 눈 투영, XR 설정, PC UI, 대사 내용, 진행·정답 판정은 변경하지 않는다. 변경은 `Assets/M/` 내부이다. 기존 폰트/XR 설정 사용자 변경과 11월 12일 측정 자료는 보존한다.

## 5개 개선

1. **시야 가장자리의 읽기 위치 수정**
   - 자막 중심은 정면 아래 **16°**, 가이드는 우측 **18° / 위 12°**를 기본으로 한다.
   - 카드 전체를 두 눈의 실제 안전영역과 수평 ±38° / 수직 ±26° 읽기 영역 안으로 보정한다. 이는 기기의 FOV 변경이 아니다.
   - 가이드의 제목과 본문을 각각 측정해 줄바꿈·높이·간격을 다시 계산한다. 폰트를 자동 축소하지 않는다.
   - 긴 화자 이름표도 VR에서 실제 글 폭에 맞춰 확장해 리본 밖으로 글자가 넘치지 않게 한다. PC 이름표 폭은 유지한다.
2. **구조대 도착 대사 중복 제거**
   - VR의 `Rescue && !ReadyToExit` 동안에는 자막만 대사를 담당하고 월드 대화 카드/선택 입력을 숨긴다.
   - 안전 확인 후에는 월드 대화/선택이 돌아온다. PC의 기존 표시 정책은 유지한다.
3. **긴 자막과 다른 UI의 겹침 처리**
   - VR 자막 폭은 최대 600포인트이며 실제 TMP 줄바꿈 높이로 카드 크기를 계산한다.
   - 검은 가독성 배경은 실제 글의 폭/높이에 맞춘다. 전체 하단 레터박스 높이는 82/720 기준을 유지한다.
   - 상태 카드·하단 안내는 실제 자막 배경 위로 간격을 두고 배치한다. 대화·선택지와 생각 카드 후보는 실제 양안 자막 영역과의 겹침을 제외한다. 고정 19% 예약값은 사용하지 않는다.
   - 자막 내용/치수/표시 상태가 바뀔 때만 의도적 재배치를 알린다. 같은 내용의 매 프레임 갱신이나 단순 머리 회전으로 월드 대화를 다시 배치하지 않는다.
   - 큰 선택지 묶음이 남아 있는 자막 옆에 들어가지 못하면 겹치는 기본 위치를 표시하지 않고 자막 종료까지 월드 카드 표시를 유예한다. 자막이 사라지면 고정 크기·거리로 다시 배치한다. 게임 진행 규칙은 변경하지 않는다.
4. **가상 읽기 깊이 정리**
   - 자막·가이드·HUD의 공통 전방 기준 평면은 **1.4m**, 월드 대화의 중심 읽기 반경은 **1.4m**이다.
   - 코너 UI는 평면 위의 좌우/상하 오프셋 때문에 중심까지의 실제 직선 거리가 약간 더 길 수 있다. 모든 글자가 정확히 같은 반경에 놓인 구면 UI라는 뜻은 아니다.
   - 기존 자막 0.45m / 가이드 0.75m / HUD 1m의 큰 차이를 없앤다.
5. **HUD가 차지하는 가로폭 축소**
   - VR은 1.4m에서 1포인트=.002m인 공통 표시 단위를 사용한다. 카메라/모니터 FOV 값에 UI 물리 크기를 연동하지 않는다.
   - 가이드와 상태 카드 폭은 340포인트로 제한하고 0.9 표시 배율을 한 번 적용한다. 대화/선택지의 기존 글자 크기는 유지한다.
   - 상태 제목·본문도 각각 높이를 측정하므로 좁아진 폭에서 서로 겹치지 않는다. PC 폭·폰트 상수는 유지한다.

## 검증

결과와 도구는 `Assets/M/CodexTemp/VRUIComfort_20261113~/`에 둔다. 이전 검증 폴더는 덮어쓰지 않는다.

- `Compile.ps1`: 현재 Unity 프로젝트 참조를 이용한 Editor/Player 분기 API 컴파일. APK/실행 파일 빌드 검증과는 다르다.
- `RunHarness.ps1`: M 내부의 독립 Unity 프로젝트에서 현재 런타임 DLL과 실제 UI 컴포넌트를 사용한다. 원본 `.meta`나 GUID를 복제하지 않는다. 소스 폰트를 별도 복제하고 임시 TMP 폰트를 메모리에 생성하므로 원본 폰트 자산을 변경하지 않는다.
- `VRUIComfortValidation`: 기록된 Quest 눈 투영, 대칭/기울어진 눈/더 좁은 눈/상하 비대칭 투영으로 실제 자막·가이드·상태·대화·선택지의 모서리, 글 영역, 시선 각도, 겹침, FOV 독립성, 구조대 표시 소유권, PC 복귀를 확인한다.
- 일반 Unity 에디터의 Play Mode 밖에서 `Tools > Wait > M > Validate VR UI Comfort`로 같은 검사를 실행할 수 있다. 테스트용 UI만 생성/제거하며 사용자 씬을 저장하거나 전환하지 않는다.

### 최종 확인 결과

- 최신 런타임(긴 VR 화자 이름표·자막 종료 시 표시 유예 유지 포함)으로 검증 **6개 그룹 모두 통과**.
- 자막 **125개**, 가이드 **40개**, 상태 카드 **65개**, 대화/선택지 **10개** 배치 확인. 자막 때문에 유예한 선택지가 자막 종료 후 배치 성공 시 복귀하는 **5개** 검사도 통과했다. 복귀 전 기본 위치가 잠깐 노출되지 않는지도 확인했다.
- 한글 제목·본문·선택지·긴 화자 이름의 글 영역과 카드 모서리를 검사했다. 자동 글자 축소는 사용하지 않는다.
- 가이드 글 중심의 최대 상방 각도는 **15.83°**, 자막 중심은 **−16.00°**였다. 기록된 Quest 투영에서 가이드/상태 카드 폭은 양안 공통영역 폭의 **약 26.0%**, 더 좁은 투영을 포함한 검사 최대값은 **약 36.8%**였다. 새 헤드셋 캡처가 아니라 현재 배치의 재계산값이다.
- Editor API, Player API 분기 및 Editor 검증 도구 컴파일 모두 오류 없이 통과. Editor API에는 기존 `VRPreviewFraming.camera`, `VRPreviewScreenSpace.camera`, `VRPreviewReading.camera`의 멤버 가림 경고 3개가 남아 있다. Android APK/플랫폼 빌드 성공을 의미하지 않는다.
- 검사는 M 내부의 독립 Unity 프로젝트에서 실제 런타임 컴포넌트와 임시 Noto CJK TMP 폰트를 조합한 것이다. `Assets/M/Scene/Wait_Elevator.unity`를 직접 실행한 통합 검사는 아니다.
