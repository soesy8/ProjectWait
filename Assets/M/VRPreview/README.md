# 임시 VR 미리보기

## 현재 기본 상태: 잠시 꺼 둠

`Wait_Elevator`의 **VR_Preview_Test 루트만 비활성화**했습니다. HMD가 없는 PC에서는 기존 PC 카메라·마우스 조작으로 실행하며 Mock HMD, 모의 손 입력, 임시 눈 해상도 변경을 시작하지 않습니다. 테스트 오브젝트·컴포넌트·코드·패키지와 실제 XR 리그/로더 설정은 삭제하거나 변경하지 않았습니다. 다시 시험하려면 아래 순서대로 루트를 켜세요. 아래의 읽기/UI 어댑터 동작은 미리보기를 켰을 때만 적용됩니다.

## 실행

1. `Assets/M/Scene/Wait_Elevator.unity`를 엽니다.
2. Hierarchy의 **VR_Preview_Test** 오브젝트를 활성화하고 Play합니다.
3. **Game 뷰를 클릭**한 뒤 조작합니다. 출력은 Inspector의 **Show Both Eyes** 설정을 따릅니다. 현재 저장된 씬은 한쪽 눈 출력입니다.
4. 한쪽 눈만 크게 보려면 Inspector의 **Show Both Eyes**를 끕니다.

| 키 | 동작 |
|---|---|
| 마우스 | 현재 선택한 머리 또는 손 회전 |
| WASD / Q·E | 선택한 머리 또는 손의 수평 / 수직 이동 |
| Tab | 머리 → 왼손 → 오른손 모드 순환 |
| `[` / `]` | 왼손 / 오른손 선택 |
| T | 선택한 손의 검지 트리거. 머리 모드에서는 오른손 트리거 |
| G | 그립. 물체 선택 키가 아님 |
| IJKL | 왼손 스틱. 기존 VR 이동 경로로 전달 |
| Esc | 기존 체험의 일시정지 메뉴 |
| R | 모의 머리·컨트롤러 포즈 초기화. 체험 진행 자체는 초기화하지 않음 |


## 서사 단계 기반 월드 대화 — 기존 수동 접기 테스트 대체

- 이전의 `VR Preview Screen Reading` Canvas를 함께 사용하지 않습니다. `VRPreviewReading`은 **원래 World Space Canvas와 실제 대화·화자·선택지·다음 버튼**을 유지하는 임시 배치 어댑터입니다. 원본 `DialoguePreview` 코드를 변경하지 않습니다.
- `VRPreviewWorldPlacement`가 현재 장면의 친구 옆·시청자 측면 후보를 중력 기준으로 세워 검사합니다. 머리 pitch/roll을 위치의 위·아래 방향으로 사용하지 않으며, 카드를 매 프레임 시야 앞으로 추종시키지 않습니다.
- 전체 읽기 영역의 물리 충돌·시선 사이 장애물과 중요 얼굴·조작부 겹침을 검사합니다. 검사를 통과한 후보가 없으면 위험한 위치에 강제로 펼치지 않습니다. 필수 대화는 안전하게 표시되기 전까지 진행 입력을 막으며, 장면이 좁으면 측면의 안전 후보를 사용합니다.
- **필수 대화는 고개를 돌리거나 이동해도 접히지 않습니다.** H 표식·접기 버튼·대화 위치 관리 단축키를 사용하지 않습니다. 새 필수 내용은 이전 표시 상태와 무관하게 자동 표시하며, Boarding의 같은 단계에서 공 받기/층 선택으로 바뀌는 안내도 구분합니다.
- 로비·탑승·구조 후 로비·1층 도착 안내는 읽기/페이지 확인을 끝내면 **확인했어요**로 관찰 단계에 넘깁니다. 이 버튼 자체는 원래 스토리를 진행시키지 않습니다. 관찰 단계에서는 대화 대신 짧은 다음 행동 안내와 구체적인 물체 하나의 강조만 사용합니다. 탑승의 두 행동 순서는 유지하며 다른 유효 물체의 hover도 보존합니다.
- 친구의 대답 선택·위치 알려 주기·다시 시도는 원래 live 선택 콜백을 사용합니다. 읽기 카드가 실제 Game 카메라에 표시된 뒤 버튼 선택을 허용합니다. 식별판 탐색·식별 정보 확인·물체 설명(친구 대답 포함)은 월드 물체 선택을 막지 않아 다른 설명으로 바로 바꿀 수 있습니다. 그 외 필수 읽기의 입력 차단은 유지합니다.
- 물체 설명은 닫기 버튼 없이 다음 물체 선택으로 교체합니다. 연출은 원래 시간·자막·fade로 진행하며 완료 노트는 원래 장면 소유를 유지합니다. 읽는 동안 안전 앵커를 유지하고 UI hover/누른 트리거가 있으면 재배치를 보류합니다.
- 본문은 현재 메인 UI처럼 한 번에 표시하고 별도 모두 보기·페이지 넘기기 입력을 요구하지 않습니다. 기존 live Button 콜백과 양손 트리거 입력을 유지합니다. 안전 안내는 메인 흐름의 설정 시간 후 자동 진행합니다.
- 기본 읽기 거리는 `1.35`, 월드 픽셀 배율은 `0.0014`, 임시 대화 글자 크기는 `32`, 선택지는 `30`입니다. 폭·여백·행 높이를 줄여 작은 카드로 배치하며 글자만 자동 축소해 끼워 넣지 않습니다. 이 값은 모의 환경용 시작값이며 실제 HMD의 편안함을 보장하지 않습니다.
- `VRPreviewScreenSpace`는 자막·HUD·조작 안내에만 독립 **Screen Space - Camera Canvas**를 사용합니다. 넓은 VR 상·하 검정 레터박스는 기본적으로 끄고 작은 자막 배경을 사용합니다. 원본 이동용 전체 comfort fade와 순간 이동 연출은 유지합니다. `Show Letterbox`는 비교용 선택 사항입니다.
- `VRPreviewFraming`은 단안·양안 미러와 좌우 눈 영역을 고려해 자막·HUD·안내를 배치합니다. 미러 정보가 없더라도 월드 대화 동기화와 넓은 레터박스 제거가 중단되어서는 안 됩니다.
- 기존 mission·tutorial의 중복 그림을 숨기고 단계 안내 한 곳만 표시합니다. 원본 활성 상태·내용·진행은 변경하지 않으며 해제하면 표시를 복원합니다.
- **Esc → 대화 다시 보기**는 실제로 표시되고 글자 공개가 끝난 최근 12개 읽기 페이지를 보여줍니다. 이전/다음 기록·긴 본문 스크롤·메뉴 복귀만 가능하며 게임은 계속 일시정지됩니다. 과거 선택을 재실행하거나 원래 페이지·진행을 초기화하지 않습니다. 기존 눈높이 맞추기는 유지합니다.
- 새 안내·읽기 확인·다시 보기 글자는 같은 Noto 원본에서 만든 **미리보기 세션 전용 런타임 폰트와 아틀라스**를 사용합니다. 원본 폰트 자산을 편집하거나 저장하지 않으며 테스트를 끌 때 전용 폰트·아틀라스·머티리얼을 함께 제거합니다.
- 해제 시 원래 UI 부모·형제 순서와 수정한 위치·배율·크기·글자 크기·레터박스·메뉴 배치를 복원하고 임시 안내·다시 보기·XRI 필터·전환 Canvas를 제거합니다. PC HUD도 원래 Canvas 모드로 갱신합니다.

## 임시 해제 / 완전 원복

- **잠깐 해제:** Play 중 `VR_Preview_Test` 오브젝트를 끄면 가상 XR과 입력 장치를 제거하고 PC 입력·포즈 드라이버를 복원합니다. 다시 켜면 재시작합니다.
- **오브젝트만 제거:** Play를 중지하고 `Tools > Wait > VR Preview > Remove Test Object Only`. Mock HMD 패키지와 전용 코드는 남습니다.
- **패키지까지 완전 원복:** Play를 중지하고 씬을 저장한 뒤 `Tools > Wait > VR Preview > Full Rollback (Remove Package)` 또는 Inspector의 완전 원복 버튼을 사용합니다.
  - 패키지 해석·재컴파일이 끝날 때까지 Unity를 열어 두세요. 이 PC에 설치된 Python/Unity CLI를 사용하는 일회성 보조 프로세스가 마지막 XR 설정 복원과 해시 검증을 마칩니다. 원복 중에는 설정을 편집하지 마세요.
  - 테스트 루트와 `Assets/M/VRPreview/`를 제거합니다.
  - 설치 전 `Packages/manifest.json`·`packages-lock.json` 및 이번 작업에서 바뀐 XR 설정을 백업으로 복원합니다.
  - 이후 사용자 수정이 감지된 설정/테스트 파일은 덮어쓰지 않고 원복을 중지합니다.
  - 메인 씬에 추가 사용자 수정이 없으면 씬 파일도 백업 바이트로 정확히 복원합니다. 이후 저장된 사용자 씬 변경이 있으면 테스트 루트만 제거해 보존합니다.
  - 필수 백업·원복 스크립트는 `Assets/M/VRPreviewSupport~/`에 있습니다. CodexTemp 정리 후에도 이 폴더를 삭제하거나 VRPreview 폴더 안으로 옮기지 마세요. 원복은 VRPreview 폴더 자체를 제거합니다.
  - 원복을 실행한 뒤 해당 지원 폴더에 생성되는 `full-rollback.json`의 `phase: complete`로 완료를 확인합니다. 이 원복 도구는 현재 PC용이며, 다른 PC로 전달할 때는 Python/CLI 경로를 다시 준비해야 합니다.

## 격리와 한계

- 루트는 **EditorOnly** 태그이며 모의 실행 코드는 `UNITY_EDITOR`로 제한합니다. 기존 메인 빌드 씬과 실제 기기용 XR 로더 목록은 바꾸지 않습니다. 기기 배포 전에는 임시 패키지도 완전 원복하세요.
- Mock HMD `1.5.0-exp.3`은 임시 시험용 실험 패키지입니다. Play 중에만 별도의 비영속 로더를 생성하고 종료 시 해제합니다.
- 가상 입력은 XRI의 표준 `XRSimulatedHMD`·`XRSimulatedController` 장치에 전달합니다. 트리거 이벤트가 기존 XRI의 같은 프레임 입력 검사에 도달하도록 **Dynamic 입력 갱신 전에 전체 상태 이벤트를 큐잉**합니다. 기존 런타임 소스나 공용 입력 액션 자산은 수정하지 않습니다.
- 카메라/컨트롤러 포즈 연결은 이 테스트 동안만 모의 장치에 직접 연결하고 종료 시 원래 액션 참조와 활성 상태를 복원합니다.
- 눈높이 보정에는 가상 추적 값과 **모의 착용 상태**를 사용합니다. 실제 센서 검증이 아닙니다.
- 실제 HMD의 광학적 가독성·멀미·추적·햅틱·기기별 OpenXR 확장·기기 성능은 검증하지 못합니다. 손 추적 테스트도 포함하지 않습니다.

## 검증 기록

2026-11-12 임시 해제 후 PC 확인: 실제 로비 포털 진입과 엘리베이터 단독 시작 모두 PC 조작 활성, 실행 중 XR 디스플레이 0개, 임시 XR 세션 없음, 시점 회전 유지와 전환 종료/취소 복원을 확인했습니다. 그림자 연속성 검사·PC 미리보기는 **`Assets/M/CodexTemp/ShadowReadyPC~/`**에 있습니다. 이는 VR 미리보기 재활성화나 실제 HMD 검증 결과가 아닙니다.

현재 단계 기반 구현의 검사·캡처·기준점은 **`Assets/M/CodexTemp/VRStageTools~/`**에 둡니다. 정책, 실제 양손 XRI 입력, 두 통화 경로와 두 탑승 순서, 일시정지 다시 보기, PC 복구, 단안·양안 캡처를 분리해 기록합니다. 최종 통합 보고서 이전의 개별 성공 기록은 전체 완료를 뜻하지 않습니다.

`VRWorldTools~/`, `VRFramingTools~/`, `VRScreenSpaceTools~/`, `VRReadingTools~/`의 결과는 **이전 단계의 역사적 기록**이며 새 단계 구현의 통과 근거가 아닙니다. 기존 실행·입력·토글 검사 도구는 `VRPreviewTools~/`에 있습니다. 인수인계 문서 작성과 CodexTemp 정리는 중단한 상태를 유지하며 기존 증거를 삭제하지 않습니다.

이미지 증거에는 Windows DPI 배율에서 잘릴 수 있는 `ScreenCaptureAsTexture` 대신 설치된 Pipeline의 **Game View 렌더 타깃 캡처**를 사용합니다. 움직임 캡처 때만 컨트롤러·레이의 장식 렌더러를 잠시 숨겼다가 복원하고 추적·입력은 유지합니다. 양손 실제 입력은 별도 검사합니다. 월드 카드 검사는 화면 픽셀 고정이 아니라 월드 좌표 고정 여부를 확인합니다. 실제 HMD·플레이어 빌드·광학 가독성·멀미·기기 성능은 별도 검증이 필요합니다.

입력 검사는 임시 키보드 이벤트와 조준 포즈를 사용하되 실제 씬의 XRI 인터랙터·물체 및 월드 UI 콜백을 통과합니다. 원복 지원 자료는 `Assets/M/VRPreviewSupport~/`를 유지합니다. 현재 설치 시점 이후 달라진 OpenXR 설정은 보호 대상이므로, 완전 원복의 해시 보호 차단을 강제로 해제하거나 새 기준으로 수용하지 않습니다.
