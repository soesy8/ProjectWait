# 투명도 전환·잔여 설명 UI 제거·파노라마 스카이박스 — 2026-11-03

## 이번 요청

- 화면에서 계속 움직이는 패널 전환을 없애고 투명도만 부드럽게 나타나고 사라지게 한다.
- 일부 설명에 남는 ‘살펴보니’ 제목과 장식 패널을 제거한다.
- 기존 Textures 폴더의 파노라마를 실제 M 씬 스카이박스로 적용한다.

## 적용

### 투명도만 전환

- `ElevatorUITransitions`의 위치·크기·회전·배율 보간과 목표 위치 추적을 제거했다. `Advance`는 CanvasGroup alpha와 텍스트 페이드만 갱신한다.
- 등장·퇴장은 지수형 Lerp alpha로, 내용 교체는 고정 위치에서 짧은 페이드로 표현한다. 문장 교체 중 두 한글 문장이 겹치지 않는 fade-through는 유지한다.
- 관찰 말풍선의 빈자리 검색은 최초 배치/화면 규격 변경 시만 실행한다. 시선·보행·서로 다른 설명에 따라 좌우를 계속 오가지 않는다.
- 친구 카드의 얼굴 회피 오프셋을 매 프레임 다시 계산하지 않는다. 화자 기준점은 유지하되 대화의 방향·크기는 새 내용/단계 배치 시에만 정한다. 이후 시선 이동에 따라 카드가 회전·확대되지 않는다.
- 버튼 hover/press의 위치 이동·확대도 제거하고 기존 Button ColorTint 페이드만 유지한다.
- 일시정지·연출 입력 잠금, 이전 첫 탑승 회전·거리 무관 선택·주머니 휴대폰·공 페이드 등은 유지했다.

### 잔여 설명 제목 제거

- Heading/ThoughtHeading을 텍스트 전환 복제 대상에서 제외한다. 비활성 원본의 이전 텍스트 복제도 즉시 정리한다.
- 현재 ThoughtCloud를 사용한 매 설명 갱신 시, 레거시 직접 자식/제목/리본을 다시 비활성화한다. 관찰 모드의 제목 문자열은 빈 문자열로 둔다.
- 예전 월드 설명 패널 15개/씬을 저장된 씬에서 비활성화하고 런타임에서도 강제로 비활성화한다. 현재 화면형 설명만 사용한다.
- 미션용 ‘나의 생각’ 제목은 필요한 경우 유지한다. 관찰 설명에는 제목·리본이 나타나지 않는다.
