호버와 설명 UI
- 설명이 있는 여러 오브젝트에 동일한 옅은 주황색 테두리를 표시합니다. 친구, 문, 표시기, 여러 조작 패널, 포스터와 층별 안내를 같은 단계에서 살펴볼 수 있습니다.
- 평소 주황색 코어는 6.5px/발광 범위 20px, 호버 시 하늘색 코어는 10.4px/발광 범위 32px입니다. 화면 픽셀을 기준으로 일정한 두께를 유지하며 호버를 벗어나면 주황색으로 돌아갑니다. 정답 한 개만 별도로 강조하지 않습니다.
- 설명 말풍선은 나타날 때 대화·선택 버튼·인물의 얼굴을 피하는 위치를 선택한 뒤 월드 위치에 고정되며, 340×136 UI 단위에 단위당 0.002m를 적용한 일정한 물리 크기입니다. 거리에 따라 확대하지 않습니다. 플레이어 쪽으로 방향만 바뀝니다.
- 설명은 호버할 때 약 0.09초에 나타나고, 호버를 벗어나면 약 0.07초에 사라집니다. 플레이어를 따라 이동하지 않습니다.
- 호버 중에도 큰 대화 말풍선과 선택·다음 버튼은 계속 보입니다. 작은 설명은 이 UI들과 다른 위치에 배치합니다.
- 모든 표시 UI는 월드 공간에 있습니다. 말풍선·글자·버튼은 지오메트리에 가려지지 않는 재질을 사용하며, 화면 고정 HUD는 숨깁니다.

마스크 기반 실루엣 강조
- Unity 6 / URP Render Graph의 전용 Renderer Feature를 사용합니다. 대상별 모든 부품을 같은 coverage 마스크에 그린 뒤 거리 기반 팽창에서 원본 영역을 빼 외곽 띠와 얕은 발광을 합성합니다. 표면 노멀이나 재질 경계는 사용하지 않습니다.
- 친구와 직원은 실제 Renderer·SkinnedMeshRenderer를 직접 그립니다. 정적 패널과 문은 마스크 전용 메시와 추적 앵커를 사용하며 추가 표시용 Renderer는 생성하지 않습니다. 같은 대상의 부품은 하나의 마스크로 묶고 다른 대상들은 독립적으로 처리합니다.
- 원본 마스크는 전체 해상도, 거리 전파는 반해상도로 처리합니다. 벽의 깊이를 비교하므로 벽 뒤 대상은 표시하지 않습니다. 실제 구멍이나 부품 사이 틈의 경계는 유지합니다.
- 이전 hull/stencil 셰이더 2개, 전용 머티리얼 4개, 구형 컴포넌트와 불필요한 배우 복제 메시 12개를 제거했습니다. 기존 사각형 표시 및 중복 발광 메시 생성 코드도 제거했습니다. 모델의 기본 갈색 카툰 선과 PC 선택 레이저는 유지합니다.
- 버튼 확인음과 누름 동작을 유지하며 눌렀을 때 같은 외곽선이 잠깐 밝고 두꺼워지도록 연결했습니다.
- M 전용 ElevatorScenePipeline.asset과 ElevatorOutlineRenderer.asset을 사용합니다. ProjectSettings와 공용 렌더러는 변경하지 않았습니다.
- 구현: Scripts/Elevator/ElevatorOutlineTarget.cs, ElevatorSilhouetteOutlineFeature.cs / Arts/Shaders/ElevatorOutlineCoverage.shader, ElevatorOutlineDistance.shader.

이동·충돌
- 농구장 미닫이문 뒤 투명벽을 이전보다 2m 더 뒤로 옮겼습니다. 벽 중심 Z=-8.4m이며 문을 지나 연결 복도를 조금 더 이동한 뒤 멈춥니다.
- 농구장 쪽 출입부의 실제 좌우 벽·고정 유리·프레임에는 메시 형태에 맞는 충돌을 추가했습니다. 움직이는 문짝과 중앙 개구부는 그대로 사용합니다. 1층 출입부에도 같은 누락을 보완했습니다.
- 3층 내려가는 계단 입구와 1층 올라가는 계단 입구를 막았습니다. 기존 계단 측면, 창가, 캐빈 뒤, 중정 경계 차단도 유지합니다.
- 1층·3층 화분 몸체에는 캡슐 충돌, 의자의 좌석·등받이·팔걸이와 운동화 벤치에는 모델 크기에 맞춘 충돌을 사용합니다.
- 직원과 계단으로 내려오는 연출은 기존 페이드 이동을 사용합니다.

- 연결된 뒤 비상벨을 다시 눌러도 대화가 진행되거나 확인음이 반복되지 않습니다.

- 문을 선택하는 행위는 살펴보기입니다. 문을 강제로 열려는 행동으로 처리하지 않습니다.

- 비상통화에 응답이 없으면 휴대폰으로 119 모의 통화를 시작하고 같은 ‘다음’ UI를 사용합니다. 실제 통화나 메시지는 발신하지 않습니다.
