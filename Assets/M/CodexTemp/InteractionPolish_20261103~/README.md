# 상호작용 연출 / 지연 힌트 개선 — 2026-11-03

## 적용 내용

1. 첫 `Entering` 탑승 중 3.4~4.7초에만 정면(180도)으로 부드럽게 돌아본다. 이후 층 버튼·공·식별판·대사 전환 때는 이전 요청대로 위치/시선을 보정하지 않는다. XR은 기존 편안한 페이드의 이동 시점에 헤드 위치를 축으로 원점 방향만 맞춘다.
2. 휴대폰을 친구의 `pelvis`에 연결하고 마주 봤을 때 오른쪽 앞주머니에서 상단이 드러나도록 배치했다. 노출 부분만 메시/선택 콜라이더로 사용하며 독립 강조를 유지한다. 친구 이동/회전을 따라간다.
3. 현재 진행에 필요한 오브젝트를 8초간 선택하지 않으면 주황→파랑→주황을 1초 주기로 반복한다. 코사인 완화된 보간값과 `Color.Lerp`를 사용한다. 잘못된 선택/단순 호버로 타이머를 재시작하지 않고, 실제 호버 시에는 파랑 강조를 우선한다. 연출·일시정지 중에는 타이머가 흐르지 않는다. 기본 씬의 UI 선택 단계에는 부적절한 정답 오브젝트를 지정하지 않는다.
4. 공을 받을 때 원래 월드 크기 그대로 친구에게서 손 쪽으로 이동하며 약 1.1초에 걸쳐 투명해진 뒤 숨긴다. 작은 공을 계속 들고 있는 표현은 제거했다. 공 전용 URP 셀 셰이더/머티리얼은 `Assets/M/Arts/`에 있으며 공용 팔레트 자산은 수정하지 않았다.
5. 관리실 통화 말풍선의 기준점을 낮은 측면 비상벨 근처로 옮겼다. 휴대폰 신고 분기는 친구 쪽 배치를 사용한다.
6. 레터박스가 표시되거나 퇴장 애니메이션 중인 동안 PC 마우스 둘러보기 감도는 평소의 10%이다. 레터박스가 사라지면 정상 복귀한다. 물리적 VR 헤드 추적은 멀미/지연을 피하기 위해 감쇠하지 않는다.
7. 화면 관찰 말풍선의 `Heading`과 `ThoughtRibbon`을 숨겨 배경 말풍선과 설명만 남겼다. 일반 미션/나의 생각 제목은 유지한다.
