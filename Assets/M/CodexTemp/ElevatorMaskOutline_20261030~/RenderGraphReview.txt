1. Validation Summary
Unity 6000.3.18f1 / URP 17.3.0 / Render Graph. 마스크 생성 → 반해상도 nearest-seed 거리 전파(Jump Flood) → 원본 마스크 제외 → 외곽 색상 합성으로 교체했다. 각 대상의 여러 부품을 하나로 묶고 대상별 마스크는 분리한다. 실제 PC 플레이와 GPU 픽셀 비교를 통과했다.

2. Confirmed Issues
최종 구현에 미해결된 렌더 패스 연결 문제는 발견하지 않았다. 검토 중 Create/Dispose 후 오래된 pass가 남을 수 있던 자원 처리 경로를 수정했다. 셰이더가 없으면 null pass 상태로 유지한다. 기존 hull/stencil/복제 메시 방식과 사각형 표시 생성 코드를 제거했다.

3. Likely Issues / Risky Assumptions
실제 HMD, 기기 빌드, XR 해상도별 GPU 비용은 확인하지 않았다. XR 텍스처 차원·슬라이스와 스테레오/인스턴싱 매크로는 유지한다. ARGBFloat 미지원 환경은 Half 포맷으로 대체하므로 큰 출력 해상도에서 정확도를 확인해야 한다. 실제 구멍이나 부품 사이 빈틈의 경계는 일반적인 실루엣 경계로 남긴다. 내부 구멍 강제 채움은 하지 않는다.
저장 검사에서 기존 XR UI Image의 Sprite 누락 8개씩을 별도로 기록했다. 작업 전후 두 씬의 m_Sprite 참조 35개씩은 모두 동일하며, 이번 강조 변경에서 해당 UI를 수정하지 않았다.

4. Recommended Fixes
이번 적용에 남은 필수 수정은 없다. 대상 HMD에서 양안 표시와 프레임 예산을 확인한다. 각 마스크·거리 텍스처는 그래프 소유이며 전역으로 공개하지 않는다. 필요한 URP Depth 입력만 요청한다. 색상 합성은 현재 컬러를 샘플링하지 않고 attachment blending으로 수행한다.
커스텀 raster blit은 대상별 scissor, 개별 MaterialPropertyBlock, 원본 마스크와 깊이 입력, 합성의 ReadWrite attachment가 필요하므로 유지했다. 단순 복사 패스가 아니다.
