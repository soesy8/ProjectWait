# UI 부드러운 전환 — 2026-11-03

## 요청 및 적용

사용자가 “러프하게”의 의도를 선택지로 확인한 뒤 **위치·크기·투명도가 부드럽게 이어지는 전환**을 선택했다.

- `ElevatorUITransitions`: 목표 레이아웃과 현재 표시 레이아웃을 분리해 패널 위치/크기/회전/배율을 약 0.22초 기준으로 보간한다. 재배치 중 재갱신되어도 현재 화면 위치에서 이어진다.
- 등장/퇴장 페이드는 0.18초 기준이다. 숨기기 요청 때 입력은 즉시 차단하고, 그림은 페이드 종료 후 비활성화한다.
- 텍스트 변경은 0.16초에 걸쳐 이전 문장 fade-out → 새 문장 fade-in으로 연결한다. 중간 캡처에서 두 한글 문장이 겹쳐 읽기 어려웠으므로 동시 크로스페이드 대신 겹치지 않는 fade-through를 사용한다.
- 같은 원문/화자/페이지의 새로고침은 페이드와 기존 타이핑을 재시작하지 않는다. 타이핑 표시 문자 수 변화도 문장 교체로 취급하지 않는다.
- TMP의 새 글자 영역은 즉시 최종 너비/높이로 맞춘다. 텍스트 영역까지 줄여서 애니메이션하면 긴 한글이 중간 프레임에 overflow되는 문제가 있어, 패널/아트만 보간하고 본문은 투명도로 전환한다.
- 친구의 얼굴을 피하는 대화 카드·화자 탭·선택 패널과 화면 관찰 말풍선 이동도 보간한다. 관찰 위치 선택에는 작은 점수 차이로 좌우를 반복 이동하지 않도록 4% 안정화 기준을 추가했다.
- 큰 단계 이동/텔레포트는 방 전체를 가로지르는 UI 비행 대신 목적지에서 페이드한다. 카메라/XR 리그/월드 화자 기준점에는 애니메이션을 넣지 않는다. XR HUD의 머리 추적에도 지연을 넣지 않는다.
- 선택 버튼의 라벨/역할이 같으면 재사용하고 콜백만 최신 revision/run으로 교체한다. 교체된 버튼은 즉시 이벤트/Graphic raycast/XR 입력을 끄고 페이드 후 제거한다.
- `ElevatorSmoothButtonFeedback`: 기존 공용 `StorybookButtonFeedback`을 M 안에서 대체한다. 버튼 hover/press의 표면 이동·작은 배율 변화도 부드럽게 보간한다. 공용 파일은 수정하지 않는다.
- 일시정지·연출 잠금·기존 화면 암전은 기존 우선순위를 유지한다. 연출 흐름·안전 대사·클릭 규칙은 바꾸지 않는다.
