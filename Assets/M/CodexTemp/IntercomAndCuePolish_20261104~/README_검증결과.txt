최종 흐름:
비상통화 연결 → 관리실의 상황 질문 → 플레이어가 ‘엘리베이터가 고장 나서 움직이지 않아요.
친구랑 둘이 있어요.’라고 답변 → 어느 승강기인지 질문 → 전면 비상벨 아래 식별판에
건물명과 승강기 번호가 적혀 있다는 안내 → 컷씬 종료 → 플레이어가 식별판을 직접 찾아 선택
→ 기존 위치 전달·안내 확인·함께 대기·두 구조요원 동행으로 진행합니다.
통화 컷씬 중에는 식별판을 미리 발견할 수 없습니다. 안내 뒤에도 자동 발견하지 않습니다.
비상통화 무응답 후 119 모의 신고도 같은 문답과 직접 단서 찾기 흐름을 사용합니다.

시간:
고장 전 친구의 슛 이야기 / 플레이어 만류 / 친구의 재답변은 각각 1.5초입니다.
통화 상황 질문·승강기 질문은 각 1.5초, 플레이어 상황 답변은 2초, 위치 안내는 2.5초입니다.
포스터 지목 대기에는 시간 제한이 없습니다.

화살표:
화면 중심 거리 30%까지는 투명, 60% 이상에서는 완전 표시, 중간은 InverseLerp로
목표 투명도를 계산합니다. 실제 투명도는 프레임 시간에 맞춘 Lerp로 따라갑니다.
거리는 뷰포트 중심을 0, 가로·세로 가장자리를 1로 정규화한 벡터의 크기입니다.
친구 시선 안내 문구도 같은 투명도를 사용합니다. 원과 지목 안내는 지목 중 유지합니다.

원형 표시:
1.5초 연속 지목이 완료되면 정확히 100%가 됩니다. 다음 대사를 바로 시작하며
표시는 동시에 1초 동안 Lerp(1 → 0)로 사라집니다. 새 대사 시작을 지연시키지 않습니다.
0%와 100% 끝값은 근삿값 갱신 생략의 영향을 받지 않도록 보완했습니다.
