통화·대기 흐름
3층에서 운동을 마침 → 아래 호출 버튼으로 탑승 → 1층 선택 → 친구의 공 받기 → 슛 재현/밖에서 하기 → 고장 → 낮은 측면 비상통화로 연결 요청 → ‘다음’으로 멈춘 상황과 인원 전달 → 식별판을 직접 살펴봄 → ‘다음’으로 위치 전달 → ‘다음’으로 안내 확인 → 놀란 친구 안심시키기 → 대기 페이드 → 직원의 바닥·경로 확인 → 하차 → 직원과 1층 이동 → 주출입구 → 완료 노트.

- 친구를 안심시키면 페이드 아웃 → 시간 경과 → 페이드 인 → 구조 안내로 이어집니다.
