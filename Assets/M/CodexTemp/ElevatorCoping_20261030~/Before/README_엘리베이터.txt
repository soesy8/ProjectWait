그 슛은 밖에서 보여줘! — 한빛 생활체육센터 3층 귀가 체험
수정일: 2026-10-30

실행
Assets/M/Scene/Elevator_Safety_Prototype.unity를 열고 Play를 누릅니다.
기존 씬의 GUID, 친구·구조원, PC/XR 입력과 공간 대화 UI를 유지했습니다.

맵
- 완성한 엘베_맵_체육센터_3층.blend의 평가된 메시를 Unity 네이티브 메시와 URP 머티리얼로 변환했습니다.
- 실제 층간 높이는 3.96m이며, 시작 위치는 지상보다 7.92m 높은 3층입니다.
- 1층 로비·주출입구를 보존하고 2층은 빈 구조, 3층은 농구장·보관함·탈의 복도·승강기 홀로 구성합니다.
- 좌측 통창, 우측 계단, 뒤쪽 자동문, 높이가 조정된 배경 건물을 포함합니다.
- 이용하는 1호기 표시는 3, 오른쪽 미사용 2호기는 5입니다.
- 전면 비상벨 높이 2.15m, 뒤쪽 측면 비상벨 높이 1.28m. 층 버튼과 열림·닫힘 버튼 모델을 두 패널 모두 유지합니다.
- 식별판: 한빛 생활체육센터 / 본관 1호기 / HB-EL-01. HB-EL-01은 가상 시설 관리번호입니다.
- 생성된 안전 포스터와 옆 층별 시설 안내를 포함합니다. 시설 안내의 현재 층 강조는 없습니다.
- 4층 이상은 안내판의 설정이며 상세 실내 모델은 1~3층과 계단 상부 랜딩까지입니다.

진행
1. 3층에서 농구를 마치고 가방을 챙긴 친구와 1층으로 귀가할 준비를 합니다.
2. 호출 버튼 또는 대사 선택지로 1호기에 탑승합니다. 측면 1층 버튼을 누르고 친구의 공을 받아 안습니다.
3. 친구의 슛 이야기에 답합니다. ‘밖에서 다시 해 보자 / 여기서 보여 줘 / 주변을 더 살펴본다’ 중 선택합니다.
4. 위험한 선택은 실제 점프·던지기 전에 Wait로 멈춥니다. 첫 판단은 History에 남고 다시 생각할 수 있습니다.
5. 앞선 판단과 무관한 설비 이상으로 운행이 정지합니다. 조명은 유지되고 마지막 표시는 3입니다. 표시만으로 정지 위치를 단정하지 않습니다.
6. 손이 닿는 측면 비상벨로 도움을 요청합니다. 포스터·시설 안내는 선택적으로 살펴볼 수 있습니다.
7. 먼저 멈춘 상황과 두 명이 있음을 알린 다음, 전면 비상벨 아래 식별판을 직접 선택해 건물·호기·관리번호를 전달합니다.
8. 다친 사람이 없고 1층으로 내려가던 중이었다고 보완하고, 문에서 떨어져 친구를 안심시킵니다. 추가 대화는 구조 조건이 아닙니다.
9. 직원이 3층 승강장 바닥과 경로를 확인한 후 나옵니다. 점검할 승강기를 다시 이용하지 않고 직원과 계단으로 1층에 내려갑니다.
10. 1층 자동문을 통해 귀가하고 3D 노트에서 도움 요청·위치 전달·함께 대기 기록을 확인합니다.
무응답 분기는 가상 119 통화로 이어지며 실제 전화나 메시지를 발신하지 않습니다.

조작
WASD: 카메라 방향으로 이동. 마우스 이동: 시점 회전. 화면 중앙의 조준점과 레이저로 물건·친구·월드 UI를 가리킨 뒤 좌클릭합니다.
숫자 1~4: 표시된 선택지. R: 3층부터 다시 시작. Esc: 일시정지 / 재개. 일시정지에서는 자유 커서로 메뉴를 클릭합니다.
F8: 단계 이동, 비상통화 응답/무응답 개발 도구.
VR: 왼손 스틱으로 이동하며 기존 컨트롤러 레이와 선택 입력을 사용합니다. 왼손 메뉴 또는 오른손 B 버튼으로 일시정지합니다. 체험자에게 점프·던지기를 요구하지 않습니다.
일시정지 메뉴: 게임 재개 / 처음부터 다시하기 / 타이틀로 돌아가기 / 게임 종료하기. 타이틀 버튼은 비활성 자리표시자입니다. 에디터에서 종료는 Play Mode를 끝내며 빌드에서는 Application.Quit을 호출합니다.
