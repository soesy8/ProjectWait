# 대화 가독성 개선 — 2026-11-03

## 적용 내용

- 공간형 말풍선·동화책 외곽 프레임·친구/비상벨 화자 위치는 유지했다. 화면 고정 자막이나 추가 자동 시점 보정은 넣지 않았다.
- 대화 본문 29→35pt, 패널 폭 510→580, 줄 간격 9, 최소 높이 230 및 내부 여백을 적용했다. 자동 글자 축소 대신 문장을 나눈다.
- `ElevatorDialogueText`가 실제 TMP 폰트로 단어 너비를 측정한다. 한글 어절 단위 줄바꿈을 우선하고 한 페이지를 최대 3줄로 나눈다. 4줄은 2+2로 나누며 글자가 잘리거나 지나치게 작아지지 않는다.
- 일반 대화의 첫 클릭/숫자 선택은 전체 표시, 다음 선택은 다음 페이지/기존 행동으로 이어진다. 월드 대화 패널에도 읽기 버튼과 작은 페이지 안내를 추가했다. 마지막 페이지를 읽은 대화 패널은 선택 레이를 가로채지 않는다.
- 타이핑 상태를 대화 원문·화자·체험 회차로 구분한다. 힌트만 바뀌거나 같은 대사가 새로고침되면 현재 페이지와 표시 시간이 유지된다.
- 연출/관리실/실패 안내는 즉시 전체 표시한다. 현재 자동 전환 대사는 모두 한 페이지 안에 들어가는 것을 검증했다. 기존 연출 입력 잠금은 유지한다.
- 친구·관리실·구조원 안내를 짧게 다듬고 의미 단위로 줄바꿈했다. 저장된 M 설정의 첫 대사와 공 전달 대사도 축약했다. 진행 조건/분기/안전 수칙의 의미는 보존했다.
- 본문 뒤에 불투명 크림색 읽기 면을 추가하여 질감/명암 변화를 줄였다. 외곽 프레임과 화자 리본은 유지한다.
- 관찰 말풍선은 대화·선택지·친구 얼굴·비상벨의 화면 투영 영역을 피하는 위치를 고른다. 친구의 대화 카드는 얼굴 선택을 가리지 않도록 내부 레이아웃만 이동한다. 플레이어/월드 화자 기준점은 이동하지 않는다.
- 먼 대화는 기본 월드 크기보다 작아지지 않으며 최대 1.45배까지만 확대한다.
- 기존 관찰 제목/패널 제거, 첫 탑승 회전, 레터박스 10% 감도, 8초 힌트, 공 페이드, 주머니 휴대폰, 거리 무관 선택은 유지했다.
