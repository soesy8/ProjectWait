# 엘리베이터 — 세 가지 안전 행동 연습

## 실행

`Assets/M/Scenes/Elevator_Observation_Choice_Test.unity`를 열고 Play를 누릅니다.

- PC: 마우스로 둘러보기, 중앙으로 가리킨 뒤 좌클릭, WASD 이동, Esc 일시정지, R 재시작.
- XR: 기존 레이와 선택 입력, 왼손 이동, 메뉴/B 일시정지. 머리 추적을 유지합니다. HMD 착용 검증은 별도로 필요합니다.
- F8 개발 도구의 **친구에게 말 걸기**로 세 번째 행동만 빠르게 확인할 수 있습니다. 처음 보는 사람의 검토는 처음부터 진행해 주세요.
- 빌드 목록·프로젝트 공용 설정은 변경하지 않았습니다.

## 방향

**승강기가 멈췄을 때 도움을 요청하고, 위치를 알리고, 친구와 안전하게 기다립니다.**

정답 물체를 많이 찾는 게임이나 능력 평가 시험이 아니라, 안내에 따라 안전 행동을 연습하는 짧은 체험입니다.

1. **도움 요청:** 실제 비상통화 버튼을 누르면 바로 연결합니다. 별도의 확인 팝업은 없습니다. 무응답 경로의 휴대폰도 바로 모의 신고를 시작합니다.
2. **위치 전달:** 식별판을 찾아 크게 읽고, ‘이 위치를 알려주기’를 직접 누릅니다. 번호 암기나 음성 인식은 요구하지 않습니다.
3. **안전 대기:** 불안한 친구를 눌러 말을 겁니다. ‘옆 벽으로 가서 같이 기다리자’를 선택하면 친구가 문에서 떨어진 옆 벽으로 이동합니다.

## 무엇이 달라졌나요?

- 도입의 농구·친구 연출은 짧은 상황 제시로 유지했습니다. 초반 포스터 선택 과제와 ‘안전하게 말렸지만 무시당함’ 구조는 정상 진행에서 제거했습니다.
- 호출·층·비상통화 같은 물리 버튼은 직접 작동합니다. 관찰 카드가 떠 있어도 비상벨을 누르면 연결합니다.
- 문과 포스터는 읽고 살펴보는 대상입니다. 문을 누르는 것만으로 위험 행동을 선택한 것으로 처리하지 않습니다.
- 포스터는 **선택적 참고 자료**입니다. 읽지 않아도 친구에게 안전한 말을 할 수 있고, 포스터를 누른다고 친구가 자동으로 움직이지도 않습니다.
- 친구의 말은 **“아직 좀 무서워… 다리가 떨리는데, 문에 잠깐 기대도 될까?”**입니다. 통증·쓰러짐·부상 설정은 추가하지 않았습니다.
- 친구를 누르면 같은 모양·색의 두 대답과 ‘주변 더 살펴보기’가 나옵니다. 말 버튼을 누르는 것이 결정이며, 그 뒤 재확인 화면은 없습니다.
- 위험한 대답은 짧게 중단시키고 이유를 설명합니다. 재시도는 친구에게 말 거는 지점만 다시 열며, 완료한 통화·정보 전달은 유지합니다.
- 구조요원 A/B의 안전 확인·퇴장·귀가 연출과 완료 수첩은 유지합니다. 수첩에는 세 행동과 안내에 따른 퇴장을 기록하며 점수는 없습니다.
- 대화는 친구끼리의 편한 말투, 관리실·119·구조요원의 짧은 존댓말로 정리했습니다. ‘공을 선택해서’, ‘저희를 선택하면’ 같은 조작 설명은 캐릭터 대사에서 빼고 HUD·버튼에만 남겼습니다. 공통 대사는 `ElevatorDialogue.cs`에서 관리해 말풍선·자막·살펴보기의 문구가 서로 달라지지 않도록 했습니다.

## 화면과 읽기

- 기존의 작은 비대화형 HUD에 **현재 상황 + 다음 행동**을 함께 표시합니다. 예: ‘친구가 문에 기대려 해요 / 친구를 눌러 말을 걸어 주세요.’ 마우스를 갖다 댈 때마다 별도 설명 말풍선을 겹쳐 띄우지 않습니다.
- 관찰 단계의 주요 **네 대상(친구·비상통화 장치·식별판·안전 포스터)**에 얇은 주황색 선택 가능 선을 계속 표시합니다. 정답 여부와 관계없이 같은 색이며, 조준할 때만 조금 두꺼워집니다. 무응답 단계에서는 식별판 대신 휴대폰을 표시합니다. 호출·탑승·식별판 찾기·구조 단계는 그때 실제로 사용할 대상을 표시하며, 개수를 맞추려고 불가능한 대상을 강조하지 않습니다.
- 문·층 버튼 등 기존의 보조 살펴보기는 삭제하지 않았습니다. 이들은 가리킬 때 같은 주황색으로 확인할 수 있습니다. 기본 갈색 카툰 외곽선은 별도로 유지합니다.
- 떠 있는 대화·정보 카드의 **열리는 거리**는 기본 **1.4m**입니다. 카드는 가까이 읽을 수 있는 것을 우선하고, 물체를 피하려고 멀리 보내지 않습니다. 글꼴 크기는 유지하고 세로 여백·버튼 간격을 줄였습니다. 겹침은 허용하며, 같은 거리에서 덜 가리는 위치를 고릅니다.
- 카드·이름표·선택 버튼은 **위치를 고정하고 한 묶음으로 플레이어의 눈 위치를 향해 회전**합니다. 머리 방향을 따라 시야 중앙으로 이동하거나 머리 기울임을 복사하지 않습니다. 옆으로 이동하면 정면이 보이도록 방향만 바뀝니다. 벽에 붙은 실제 포스터·식별판은 회전하지 않습니다. 이후 카드를 두고 멀리 걸어가면 읽기 거리는 늘어납니다.
- 시야 중앙의 부드러운 타원 영역에서 **종이 배경·테두리·장식만** 투명해집니다. 이전 버전의 가로·세로 반경을 각각 **정확히 2배**로 확장했습니다. 기준 각도 12°/10°의 탄젠트 반경에 `radiusScale = 2`를 적용하므로 같은 깊이에서 폭·높이가 2배이고 면적은 약 4배입니다. 중심 배경 알파 0.12와 전환 설정 0.16초는 유지했습니다. 여러 배경 층이 겹치므로 최종 합성 불투명도는 이 값과 다를 수 있습니다.
- 글자와 대답·진행 버튼은 투명화하지 않습니다. 갈색 글자에는 좁은 종이색 가장자리를 줘 어두운 배경에서도 대비를 보완합니다. 효과는 런타임 머티리얼에만 적용하며 폰트·공용 UI 머티리얼은 변경하지 않습니다.
- 투명 영역의 보이지 않는 ‘전체 카드 읽기’ 버튼은 뒤 물체를 가로막지 않습니다. 대답·진행 버튼은 언제나 UI 선택을 우선하며, 통화 안내·위치 확인·일시정지 등의 기존 진행 잠금은 유지합니다. 실제 눈 추적 없이 카메라/머리 정면을 사용하며, 시선 유지 시간이나 별도 확인 단계는 추가하지 않았습니다. HUD와 완료 수첩·일시정지 메뉴에는 이 투명화 효과를 적용하지 않습니다.
- 바라보기 화살표·링·시선 유지 판정과 별도 ‘친구를 보세요’ 패널은 제거했습니다. 직렬화 참조 보존용 컴포넌트와 기존 GUID만 비활성 상태로 남깁니다.
- 연출을 보지 못해도 친구의 문 접근·안전 벽 이동·함께 대기·구조대 도착·안전 확인 완료를 HUD로 알 수 있습니다. 중요한 읽기 카드가 화면 밖에 있거나 행동 버튼이 충분히 보이지 않을 때도 기존 HUD가 진행 방법을 알려 줍니다. 구조 안내는 큰 카드와 중복하지 않고 HUD를 사용합니다.
- 통화 질문은 3초, 상황 답변은 4.5초, 친구의 긴장 대사는 5초로 확보했습니다.
- **식별판 위치 안내와 안전 대기 안내는 시간으로 사라지지 않습니다.** 읽은 뒤 진행 버튼을 누릅니다.
- 20초 문장 힌트·40초 대상 강조를 유지하며 시간 초과 실패는 없습니다. 새 음성·TTS는 추가하지 않았습니다.

## 격리와 검증

- 원본: `Assets/M/Scene/Elevator_Safety_Prototype.unity`. 테스트 사본만 별도 GUID로 사용합니다.
- 런타임: `Assets/M/Scripts/ObservationTrial/`, 네임스페이스 `ProjectWait.M.Elevator.ObservationTrial`.
- 설정: `Assets/M/Scenes/Elevator_Observation_Settings.asset`.
- 캐릭터·텍스트 프리팹과 동적 한글 폰트는 테스트 사본으로 격리했습니다. 공용 모델·셰이더·환경 자산은 읽기 전용으로 재사용합니다.
- 현재 검증·캡처: `Assets/M/Documentation/ObservationTrial_Dialogue_20261106/`.
- 이전 버전의 증거는 `ObservationTrial_20261106/`, `ObservationTrial_Confirmation_20261106/`, `ObservationTrial_Focused_20261106/`, `ObservationTrial_Visibility_20261106/`, `ObservationTrial_NearUI_20261106/`에 보존했습니다. 최초 원본 해시·격리 목록은 첫 폴더에 있습니다.
- `FlowValidation.json`: 두 통화 경로, 직접 버튼, 필수 안내 읽기, 포스터 선택 여부, 친구 대답·재시도·초기화 검사.
- `RuntimeValidation.json`: 실제 중앙 레이/버튼 이벤트, 네 개의 주황색 선택 가능 표시, 카드 전체 화면 배치·근거리·1080p 투영 글자 크기·4:3 카메라, 이동에 따른 방향 보정과 위치 고정, 투명 영역의 완만한 경계·배경 픽셀의 실제 렌더링 변화·글자와 버튼 보호·PC/XR 입력 필터 검사. 기존의 같은 선택지 스타일·일시정지·상황 복귀·재시도·구조·수첩 검사도 유지합니다.
- `DialogueValidation.json` / `DialogueCopy.json`: 두 통화 경로와 친구·구조 장면의 실제 출력 문구, 카드와 자막의 일치, 4:3 자막 길이, 설정 자산의 문구 갱신과 숫자 보존을 검사하고 공통 대사 목록을 남깁니다. 말맛의 자연스러움은 편집 판단이며, 자동 검사로 사용자 만족을 입증하지는 않습니다.
- `PlacementMeasurements.json`: 대표 시점의 실제 카드 열 전체와 보호 영역의 투영 겹침 면적입니다. **이 버전은 근거리 가독성을 위해 겹침을 허용하므로, 이전 버전의 무겹침 조건을 합격 기준으로 사용하지 않습니다.**
- `05c_FocusOpaqueReference.png` / `05d_FocusWindow.png`: 같은 시점의 배경 불투명/중앙 투명화 렌더링 비교입니다. 검증용 불투명 참조를 만들 때만 효과를 잠시 끄며, 씬에는 저장하지 않습니다.
- `RealtimeValidation.json`: 정상 Update 시간으로 진행한 전체 경로 검사. 수동 시간 점프와 개발 단계 생략 없이 진행합니다.
- `SceneValidation.json`, `Compilation.json`, `OriginalPreservation.json`: 참조·컴파일·원본 보존 검사.
- 검사 결과와 개수는 현재 폴더의 `FlowValidation.json`, `RuntimeValidation.json`, `RealtimeValidation.json`, `SceneValidation.json`, `OriginalPreservation.json`을 기준으로 확인합니다. 기존 XR 장치·임포터 경고는 남아 있습니다.
- 최종 결과: 흐름 **67개**, 재생 **119개**, 문구·표시 **104개**, 정상 시간 전체 경로 **77.2초** 통과. 새 콘솔 오류·컴파일 오류·셰이더 오류·스크립트 및 직렬화 참조 누락은 없습니다. 자막은 글자 크기를 유지한 채 기존 82pt 검은 띠 안에서 두 줄이 들어가도록 글상자 높이를 맞췄습니다.
- 자동 검사는 **처음 보는 사람의 이해도나 HMD 사용성을 입증하지 않습니다.** 실제 장치 입력, HMD 양안 가독성·손 추적, 기기 빌드·성능은 미검증입니다. 기존 XR 장치·임포터 경고는 공용 설정을 수정해 숨기지 않습니다.
