## 공통 규칙

- 로비 왕복·재시작은 기존 **물방울 씬 전환**과 정면 확인을 사용한다. 이미 지속 중인 로딩 객체도 포털의 한국어 글꼴을 갱신할 수 있어 진입 경로에 따른 글리프 누락을 막는다.
- 레터박스는 공통 `LevelLetterboxLayout`의 200/720 기준과 중력 방향·실제 양안 투영 계산을 사용한다. 텍스트는 띠 안에 넣지 않는다. 카메라 FOV·XR 추적 포즈는 연출용으로 덮어쓰지 않는다.
- 기존 종이 프레임·화자 이름표·친구 초상을 **별도 월드 Canvas**에서 재사용한다. 카드 표시 시 배치하고 매 프레임 고개를 따라 붙이지 않는다. 본문은 갈색이며 가림 방지 TMP Overlay를 사용한다.
- 심부름 단계에는 책상 위의 종이색 표식과 청록 화살표로 서류 놓는 위치를 안내한다. 원본 디버그 트리거 큐브는 숨기되 실제 서류/책 모델은 놓은 뒤 보이도록 유지한다.
- 교사와 함께 나가는 자동 이동은 `ComfortBlackout`과 같은 **1.3초 이동 노출 + 0.5초 페이드 + 0.3초 암전 유지 + 0.5초 복귀**를 따른다. 완전히 가려진 프레임을 실제로 한 번 그린 뒤 NPC 경로를 마치고 플레이어 발 위치만 옮긴다. 일반 WASD 보행을 매번 페이드하지는 않는다.
- 일시정지 시 대사, NPC, 교사 대기, 자동 이동·페이드 시간이 멈춘다. 메뉴와 XR 추적은 계속 동작한다. BGM은 재시작하지 않고 설정 음량의 40%로 낮춘다.
- `ExperiencePauseMenu.prefab`의 설정을 그대로 사용한다. 글자 크기·대사 속도·이동 속도·효과음·진동 설정과 높이 재보정/새 클릭 보호를 연결했다.
- PC에서는 원본 카메라의 음수 로컬 높이 오프셋을 정규화한 뒤 공통 눈높이를 적용한다. XR은 추적·착용 값과 안정된 높이를 기다려 바닥 오프셋만 보정하고 도착 화면을 연다. 실제 추적 카메라의 로컬 포즈를 직접 수정하지 않는다.
- 하나의 이동 코드만 플레이어를 움직이도록 B2의 중복 XRI locomotion provider를 씬에서 비활성화했다. UI 입력은 단일 XRUIInputModule의 마우스 입력과 사무실 컨트롤러 레이 처리를 분리해 중복 클릭을 막는다.
- 완료 노트에 재시작·광장 복귀를 연결하고 양쪽 페이지 배경도 가림 방지 종이 재질로 표시한다.
- 사무실 내부가 검은 실루엣으로 소실되지 않도록 **이 씬의 환경광만** 낮은 평면광으로 조정했다. 정전 시 원본 실내등 소등은 유지한다. 전역 렌더링 설정은 바꾸지 않았다.
