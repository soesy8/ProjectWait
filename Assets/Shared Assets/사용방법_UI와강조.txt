공유 UI · 오브젝트 강조 사용 방법
================================

먼저 체험하기
Assets/Shared Assets/Examples/SharedAssets_Showcase.unity를 열고 Play하세요.
위쪽에는 UI 9종, 아래쪽에는 강조할 오브젝트 3개가 있습니다.
‘강조 켜기 / 강조 끄기 / 반짝이기 / 파란 강조’를 클릭하면 효과를 확인할 수 있습니다.


1. 내 씬에 강조 적용하기
-----------------------
① 씬을 Assets 아래 원하는 폴더에 저장합니다. Assets/M 밖의 씬도 됩니다.
② Tools > Wait > 강조 세팅을 열고 ‘자동 설정’을 한 번 누릅니다.
③ 자동으로 선택된 오브젝트의 Inspector에서 Shared Object Highlight를 찾습니다.
④ Objects 목록을 펼치고 강조할 Hierarchy 오브젝트들을 끌어 넣습니다.
   여러 개를 선택해 Objects 목록 제목에 함께 끌어 넣어도 됩니다.
⑤ 씬을 저장하고 Play합니다. 연결한 오브젝트들에 주황색 강조가 표시됩니다.

추가 컴포넌트나 콜라이더를 강조 대상에 붙일 필요가 없습니다.
Include Children이 켜져 있으면 연결한 오브젝트의 자식 메시까지 자동으로 수집합니다.
MeshRenderer와 SkinnedMeshRenderer를 지원합니다. Sprite, Particle, UI는 대상이 아닙니다.
비활성 오브젝트와 꺼진 Renderer는 표시하지 않으며, 활성화하면 다시 표시합니다.
빈 슬롯, 같은 오브젝트의 중복 연결, 부모·자식의 겹친 연결은 중복 렌더링하지 않습니다.
Play 중 Inspector에서 목록을 변경해도 자동으로 다시 수집합니다.

모양 바꾸기
- Idle Color / Idle Width / Idle Halo: 기본 강조의 색·외곽선 두께·번짐.
- Hover Color / Hover Width / Hover Halo: 파란 강조 상태의 모양.
- Color Transition Duration: 두 색 사이의 전환 시간(초).
- Highlight On Start: 실행하자마자 강조할지 선택합니다.
- 그룹마다 다른 모양을 쓰려면 빈 오브젝트에 Shared Object Highlight를 추가하고 목록을 나눕니다.
  같은 메시를 여러 그룹에 동시에 연결하면 효과가 겹칠 수 있으므로 한 그룹에 연결하세요.

버튼이나 시나리오에서 제어하기 — 필요한 경우에만
Button > On Click()에서 강조 목록 컴포넌트가 있는 오브젝트를 연결합니다.
- SharedObjectHighlight.Show(): 강조 켜기.
- SharedObjectHighlight.Hide(): 강조 끄기.
- SharedObjectHighlight.SetHighlighted(bool): 체크값으로 켜고 끄기.
- SharedObjectHighlight.SetHovered(bool): true는 파란 상태, false는 기본 상태.
- SharedObjectHighlight.Flash(): 짧게 반짝이기.
각 메서드는 그 컴포넌트의 Objects 전체에 적용됩니다.
자동 포인터·거리 판정은 하지 않습니다. 필요하면 기존 입력/상호작용 이벤트에 연결하세요.
코드로 실행 중 Objects를 교체했다면 Rebuild()를 호출하면 됩니다.

‘자동 설정’이 하는 일
- 현재 씬에서 쓰는 URP 자산을 감지합니다.
- 렌더링 설정을 Shared Assets/Highlight/Rendering에 복사하고 셰이더와 피처를 연결합니다.
- 씬에 렌더링 설정과 강조 목록 컴포넌트를 연결하고 씬을 저장합니다.
- 다시 눌러도 같은 렌더링 자산과 피처를 재사용하며 기존 Objects 목록을 유지합니다.
기존 프로젝트의 Graphics/Quality 할당과 원본 렌더링 자산은 유지합니다.
씬별 설정은 Play Mode에서 적용됩니다. 표시 확인은 Game 창에서 Play하며 진행하세요.
고급 설정의 ‘현재 씬 연결 및 저장’을 끄면 렌더링 자산만 설정합니다.


2. UI 패널 사용하기
------------------
프리팹 위치: Assets/Shared Assets/UI/Prefabs

DialogueCard           대화창 — Speaker, Dialogue 텍스트 수정
IntercomDialogueCard   관리실 대화창 — Speaker, Dialogue 텍스트 수정
ThoughtCloud           생각 말풍선 — Heading, Thought 텍스트 수정
ObservationCard        관찰 설명 — Heading, Description 텍스트 수정
MissionCard            미션 안내 — Heading, Objective 텍스트 수정
ChoiceCard             선택 버튼 3개 — 각 버튼의 Label과 On Click() 수정
CompletionCard         완료 기록 — Title, Done0~2와 KeepMemory 버튼 수정
PausePanel             일시정지 화면 — ResumeButton, RestartButton, TitleButton 연결
NextButton             다음 버튼 — DialogueNext의 Label과 On Click() 수정

① 원하는 프리팹을 Project 창에서 Hierarchy 또는 Scene 창으로 끌어 넣습니다.
② 프리팹의 위치·방향·크기를 원하는 곳에 맞춥니다.
   World Space Canvas가 포함되어 있으므로 그대로 씬에 배치할 수 있습니다.
   Canvas 아래에 다시 넣으면 부모의 크기가 곱해지므로 전체 크기도 확인하세요.
③ Canvas > Event Camera에 플레이어 카메라를 연결합니다.
④ 자식 TextMeshPro의 Text Input에서 문구를 바꿉니다.
⑤ 버튼이 있으면 Button > On Click()에 팀원 씬의 동작을 연결합니다.
   프리팹에는 엘리베이터의 시나리오·재시작·일시정지 동작이 들어 있지 않습니다.
   PausePanel 자체가 게임 시간을 정지시키거나 씬을 이동시키지는 않습니다.

마우스로 버튼 사용하기
- 씬에 EventSystem을 하나만 둡니다.
- 현재 프로젝트처럼 새 Input System을 사용하면 Input System UI Input Module을 씁니다.
- Event Camera를 연결해야 World Space UI의 포인터 위치를 올바르게 계산할 수 있습니다.
- 이미지·폰트·버튼의 가리킴/누름 피드백은 프리팹에 포함되어 있습니다.

XR에서 버튼 사용하기
- Tracked Device Graphic Raycaster는 프리팹에 포함되어 있습니다.
- 씬의 XR UI Input Module과 XR 포인터는 기존 XR Rig 설정을 사용하세요.
- 입력 모듈은 씬의 EventSystem에 맞춰 하나의 구성을 사용하세요.
- 현재 프로젝트의 Unity 6000.3.18f1 / URP 17.3 / XR Interaction Toolkit 3.5.1 기준입니다.
  에디터에서 렌더링과 포인터 이벤트를 검증했으며 실제 HMD 착용 검증은 별도입니다.


3. 팀에 공유하기
---------------
같은 프로젝트: Shared Assets/UI와 Shared Assets/Highlight를 .meta까지 함께 Git에 올립니다.
예제 씬도 공유하려면 Shared Assets/Examples를 함께 올립니다.
다른 프로젝트: 위 폴더들을 선택하고 Export Package에서 Include Dependencies를 켭니다.
UI의 이미지·한글 폰트·텍스트 셰이더는 UI 폴더 안에 모아 두었습니다.
상대 프로젝트에는 uGUI/TMP, 새 Input System, XR Interaction Toolkit이 필요합니다.
강조 효과는 Unity 6 + URP + Render Graph 기준입니다. Compatibility Mode는 지원하지 않습니다.
받은 프로젝트에서는 강조 세팅의 ‘자동 설정’을 한 번 실행해 해당 씬의 URP에 연결하세요.
기존 엘리베이터 씬의 참조를 유지하기 위해 강조 내부 스크립트에는 Elevator 이름이 남아 있습니다.


잘 안 보일 때
-------------
강조: 씬 저장 → 자동 설정 → Objects 연결 → Highlight On Start 체크 → Play 순서로 확인합니다.
      대상에 MeshRenderer/SkinnedMeshRenderer와 메시가 있고 활성 상태인지 확인합니다.
      기존에 다른 강조 컴포넌트가 붙어 있다면 같은 대상의 효과가 겹치지 않는지 확인합니다.
UI: Canvas 위치·방향·크기와 카메라 시야를 확인합니다.
버튼: EventSystem, 입력 모듈, Canvas의 Event Camera, Button의 On Click()을 확인합니다.
