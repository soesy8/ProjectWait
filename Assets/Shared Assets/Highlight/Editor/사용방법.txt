공유 강조 효과

1. 씬을 Assets 아래에 저장합니다.
2. Tools > Wait > 강조 세팅 > 자동 설정을 한 번 누릅니다.
3. 선택된 오브젝트의 Shared Object Highlight > Objects에 강조할 오브젝트들을 연결합니다.
4. 씬을 저장하고 Play합니다. 자식 MeshRenderer/SkinnedMeshRenderer도 자동으로 연결됩니다.

렌더링 자산은 Assets/Shared Assets/Highlight/Rendering에 복사합니다.
원본 URP/Renderer와 프로젝트의 Graphics/Quality 할당은 유지합니다.
다시 실행해도 복사본과 피처를 재사용하고 기존 강조 목록은 유지합니다.

상세 사용법: Assets/Shared Assets/사용방법_UI와강조.txt
예제 씬: Assets/Shared Assets/Examples/SharedAssets_Showcase.unity

Unity 6 / URP / Render Graph용입니다. Compatibility Mode는 지원하지 않습니다.
에디터 도구, Runtime, Shaders를 .meta와 함께 공유하세요.
