# 횡단보도 main 선별 통합 결과

## 범위

- 기준 main: `f74a815f45216f91da8347f8a9f4cf8f3bd4883d`
- 원본 Y: `36faeac57befefe3b81d37a589f6b887c210bdca`
- Y의 전체 변경/삭제/패키지 설정은 병합하지 않았다. 횡단보도와 직·간접 의존 파일 355개를 가져왔다.
- 원본 씬과 자산의 GUID를 유지했다. 이미 존재하는 3.5.1 XR 샘플과 겹치는 **3.4.1 폴더**의 GUID만 새로 발급했다. 기존 main 폴더의 GUID는 보존했다.
- `SoftStreetSetStatic.asset`의 190,470,925바이트 LFS 원본을 복구했다. 폴더 내부 `.gitattributes`로 LFS 추적을 유지한다.
- Packages와 기존 전역 렌더링 설정은 유지한다. 횡단보도만 사용하는 렌더러/파이프라인을 `Assets/M/Arts/Rendering/Crosswalk/`에 만들었다.

## 연결

- 빌드 씬 순서: `Wait_Robby` → `Wait_Elevator` → `CrosswalkScene`.
- 로비의 횡단보도 포털이 실제 씬을 연다. 기존 구체/하늘 전환을 재사용한다.
- 로딩 문구: “학교를 마치고, / 친구와 함께 집으로 돌아가는 길이에요.”
- 원본 `m_WaitForStartScreen=0` 자동 시작, 월드 대화/선택지, 90도 회전과 수평 레터박스를 보존했다.
- Esc / 왼손 메뉴 / 오른손 보조 버튼: 일시정지 메뉴.
- 메뉴: 계속하기, 처음부터 다시, 로비로 돌아가기, 끝내기.
- 일시정지와 로딩 중에는 이동·대사 대기·연출 시계·오디오가 멈춘다. HMD 추적과 메뉴 UI는 유지한다.
- 종료 확인 이벤트는 로비 복귀에 연결했다.
- 새 문구 152글자를 별도 1024×1024 고정 한국어 글꼴에 포함했다. 원본 글꼴과 원본 아틀라스는 변경하지 않는다. 종이 카드보다 나중인 4101 큐에서 글자를 그린다.

## 검증

- Unity 6000.3.18f1, 실제 main 프로젝트의 Pipeline 0.8.0-exp.1에서 실행.
- 기존 컴파일·정적·배치 계산: **282개 통과**.
- 에디터 씬/참조/셰이더/LFS/글꼴: **19개 통과** (`edit-validation.json`).
- 실제 플레이의 로비 진입/로딩/정지/재개/재시작/복귀: **40개 통과** (`play-validation.json`).
- 기존 엘리베이터 진입·로딩 문구·일시정지 회귀 확인: **10개 통과** (`elevator-regression.json`).
- 총 **351개 검증 통과**. 프레임 증가, 실제 Esc 입력 액션, 메뉴의 PC UI 레이캐스트도 확인했다.
- 최종 콘솔 오류 **0개**. 기존 VRPreview 코드의 CS0108 경고 3개와 장치 환경 경고는 이번 작업 범위에서 수정하지 않았다.
- 로딩/일시정지 캡처에서 한글 가독성과 실제 화면 표시를 확인했다.
- **미검증:** 실제 HMD/양손 컨트롤러 조작, 전체 교육 3상황 완주, Android/PC 최종 플레이어 빌드.
